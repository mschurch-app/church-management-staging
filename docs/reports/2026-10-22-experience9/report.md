## 找到並修正的問題

1. **App 新版安裝會失敗**：快取清單重複列入相同版本的 `app-resume.mjs` 與 `app-runtime.mjs`。獨立 Chrome 實際回報 `Cache.addAll(): duplicate requests`；失敗安裝的 Worker 無法進入 ready。現在先以 Set 去重，再交給原本的原子安裝流程；去重後已確認真實 Worker 可安裝、接管、離線顯示原網址恢復頁、連線後重試及開啟時接管新版。新增去重回歸，安裝等待有 15 秒期限，避免測試無限停住。先前 VM 的 addAll stub 沒有模擬瀏覽器拒絕重複項目，22 項 VM 通過不足以驗證實際安裝。
2. **服事意願編輯遺漏年度資訊**：恢復編輯中的「恩典腳蹤」與年度選擇，切換年度時保留目前姓名、項目、日期及確認步驟；不發出登記寫入。忙碌時一併鎖定 select／textarea，避免操作中切年度重繪控制。
3. **M+ 首頁表頭偏矮**：原本在本機合成內容條件下約 129／136 px，調整為共用正常表頭的至少 164 px；保留可依內容長高的布局。
4. **五處文字對比不足**：設定區說明、營隊空清單、媒體未連線標籤、M+ MY WEEK、小計卡片文字。修正在 `experience-accessibility.css` 的限定元件及 M+ 原有樣式，沿用現有表面與品牌色。修復前實測比值包括 4.48、4.09、3.9、4.02、4.34；原門檻為一般文字 4.5、大字 3。

新增樣式、M+ 樣式、服事登記模組與 App shell cache 版本為 `20261022-experience9`；保留其他功能的現有資源版本。使用原本的功能、資料操作與通知規則，沒有資料庫遷移或權限調整。

## 固定測試維護

初次完整清單有 5 組失敗。除上述實際問題，也修正改版後失效的 fixture 與操作路徑：

- 同工帳號頁改用現有「設定」入口，展開協調範圍與移除區，補齊事工分工與已核准會友綁定的合成回應；保留回應遺失、相同 request ID 重試、單次審計及雙登入身分撤權。另驗證未獲全事工統整權限的同工不能藉設定擴權。
- 原有常用／收納盒操作在火樂首頁驗證；M+ 改版入口由原有 phase2 的五大入口轉址檢查與本次全頁掃描涵蓋。火樂限制同工只出現服事安排，不出現限 M+ 的兩個協調入口。
- 服事登記文案檢查改為目前「已收到服事意願」的回覆，仍檢查實際筆數、候補與防重複寫入。
- Canva callback 本身沒有管理表頭，改驗證取消授權結果、所選堂會返回連結及手機／桌面不溢出；40 個有管理表頭的頁面仍逐頁驗證 164 px。
- 更新／離線測試改匯入正式頁面同一個 runtime 版本，避免以不同網址另外載入一份模組。
- 色彩掃描各頁使用獨立瀏覽器 context，隔離前頁 Worker；保留全部 41 頁及原有對比門檻，頁面轉址不會被靜默略過。
