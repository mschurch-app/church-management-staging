# 讀經後返回澆水入口修正

## 原因

澆水功能仍存在於每日操作卡，但手機採單欄版面，生命數值及成長卡排在它前方。讀經完成只移動焦點且禁止捲動；恩典小物的「回花園」捲到樹圖後同樣沒有把澆水入口帶進視野，造成使用者以為功能消失。

## 修改

- 在花園正下方、布置工具之前新增同一份進度控制的澆水操作卡，沿用共用系統字體、按鈕、圖示與色彩。
- 明確呈現尚未讀經、可以澆水、已經澆水三種狀態；不要求再次讀經才能看到入口。
- 讀經完成及關閉今日恩典小物後，統一捲到這個入口；保留底部導覽和 iPhone 安全區間距。
- 開啟小物裝備包時保留裝備包流程；補讀仍回到原日期的補讀與澆水浮窗。
- 兩處澆水入口共用原有儲存操作。等待時停用並顯示狀態，成功後回到樹圖播放活水動畫；失敗顯示恢復提示。
- 完成與重讀依已保存紀錄判斷，已澆水不再次開放或增加獎勵。每日恩典小物、同工組隊及後端權限維持既有契約。
- 更新會員頁、樣式、核心與 October 入口資源版本；未變更後端或業務資料。

## 證據與待驗收

- JavaScript 語法與差異格式檢查完成；獨立代理靜態檢閱未發現阻擋問題。
- 未新增或執行功能測試，未操作真實會友進度。
- Mac Safari、Chrome、iPhone 17／LINE 的捲動、焦點、鍵盤與活水動畫仍待實機驗收；未宣稱 99% 達標。
- 發布結果與公開資源比對另記錄於 `watering-return-release.json`。
