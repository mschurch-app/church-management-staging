# 講道 IG／YouTube 審核工作區

2026-10-23。本機完成，尚未發布。基準為已上線 PR #251：`3dbe5a94b415b01b7ee32e0a5be0baebea460f88`。接續共用介面框架的「其他非試點頁面逐項推廣」，本批處理講道社群審核。

## 使用上的改變

- 手機提供圖片與影片、基本資料、IG 貼文、講道內容、儲存與送審及 YouTube 字幕的分區捷徑。目標可接續鍵盤操作；切換區域保留已填內容，沒有觸發儲存或發布。
- 桌面將素材與內容並排，IG 貼文提前至基本資料後，方便核對圖卡與文案。原有講道大綱、重點、應用完整保留。
- 編輯區增加較大的貼文欄位及長度提示。計數沿用 maxlength 的 UTF-16 方式，與平台最終接收結果分開。
- 儲存與送審維持單一表單，操作區回到文件流；結果與重試提示佔滿操作區寬度。返回分區入口可回到頁面導覽。
- 候選圖片保留原 radio 選取，橫向捲動可見下一張，支援鍵盤選擇。沒有產生或替換正式素材。
- 使用現有語意色、系統字體與卡片規範；僅此頁加入專屬樣式。表頭已有管理首頁入口，因此隱藏重複的單一首頁卡片。

## 操作缺陷修復

隔離測試確認：原本 IG 核准後但發布失敗時，`submitted` 會連帶停用獨立的 YouTube 控制。本批讓 YouTube 的可操作狀態依其審核角色、工作狀態及進行中的操作判定，保留 IG 核准結果及發布重試。Reel 上傳完成後同樣恢復相應控制。沒有改變後端授權、通知或發布 API。
