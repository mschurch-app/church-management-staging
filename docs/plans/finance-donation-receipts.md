# 收據開立：金錢與物品

2026-10-28，依使用者本次確認：現在啟用金錢收據；捐物可隨時開立、保留選填金額；有金額才納入整批會計匯出；列印可選單筆或批次。此規格取代原規格「2027 年起才能開立」的限制，其餘未實作會計範圍保持待辦。

## 使用方式

M+ 行政「奉獻與財務」以及既有奉獻／支出頁提供「收據開立」。分為金錢、物品兩類，可搜尋最近 200 筆、編輯草稿、正式開立、作廢、預覽與列印。

- 金錢捐贈：日期、實際捐贈人、收據抬頭、選填地址、專案、金額及原始收入參照。適用 2026 年起、且不晚於台北當日的實際日期。
- 捐物存查：日期、捐贈人、抬頭、專案、原始接收紀錄，以及多項名稱／數量／單位／規格。不限金錢系統啟用年度，不能填未來日期。金額可空白；填有金額時另填金額依據。無金額物品只存查，不進會計匯出。
- 籃球營報名費：金錢工作區內有獨立入口，唯讀帶入正式已付款報名。透過既有營隊收據函式核發、驗證付款及外部收據衝突；保留營隊既有編號與重印行為，不改用新捐贈序號。資料未齊或未索取收據時回營隊管理頁確認。營隊資料仍需原有營隊權限。

正式捐贈收據開立前，由管理者確認協會正式名稱、統編、地址、兩類編號前綴及 2026 年最後已用流水號。編號為「前綴－捐贈年度－六位流水號」；2026 年銜接舊流水號，其他年度各自從 1 起。相同協會所有專案共用同類、同年度序列。資料不猜填，不預植合成協會或序號。

由授權同工人工核對原始收入／物品接收紀錄、實際受領人及是否已在舊系統／紙本開立，再確認核發。本版不新增收入、不自動核准帳務、不匯入舊收據，也不宣稱能對未匯入的紙本資料自動防重。

## 匯出與列印

- 依起迄日期產生一份會計 CSV，合併金錢、有金額的物品，以及操作者有權限讀取的營隊收據。草稿及無金額物品不納入。作廢列保留原金額與作廢狀態，有效金額為 0，供會計對照，不能再認列為有效收入。
- 匯出是資料檔，不代表寄送會計或已登帳。多次匯出保留相同收據編號，供對帳防重。
- 單筆列印目前明細；批次可跨分頁勾選一般與營隊收據，一次最多 50 筆，印前逐筆重新讀取。每筆從新頁開始，草稿／作廢標記狀態。使用瀏覽器列印或另存 PDF，不自動寄送。

## 權限與資料

新表在 finance 私有 schema，啟用 RLS 並撤銷 anon/authenticated 直接權限。public RPC 為 invoker、僅 service_role 可執行，委派至私有受限函式。Edge Function 驗證 Auth token，actor 由驗證後使用者取得；不採信請求指定 actor。

有效 M+ 管理者、財務登錄者或指定會計可整理捐贈收據草稿；管理者、現金核對／核准者與指定會計可核發、作廢及匯出。營隊操作另檢查既有 heat_camp 查看／匯出權限。一般會員、其他堂會及停用帳號不能存取。入口由獨立 profile 篩選，不以常用捷徑授權。

捐贈寫入有版本、冪等鍵及資料庫鎖，正式號碼原子取得；同類來源已開立或作廢便保留占用，不能重複核發。作廢保留原紀錄及原因、不回收號碼、不退款；後續更正重開流程須另行設計。開立單位快照隨收據保存。登入變更清除舊資料，晚到回應不能重新顯示舊帳號內容。

## 驗證及未涵蓋範圍

隔離 Postgres、Edge handler 與 CSV 測試涵蓋分號、舊號接續、重試、作廢、日期、估價依據、過期版本、停用／跨堂、直接 API 權限、營隊舊流程委派與合併匯出。介面用合成資料驗證，不試開正式收據。2027 年測試僅將測試 SQL 的「當日」常數換成固定日；2026 年接續使用真正當日。

此版沒有年度彙總、身分證／稅務同意及稅務匯出、Email 寄送、照片接收、與已入帳奉獻自動連結或自動登帳。原生 iPhone、Mac Safari 列印仍另驗收，不以 viewport 或預覽代表實機列印。
