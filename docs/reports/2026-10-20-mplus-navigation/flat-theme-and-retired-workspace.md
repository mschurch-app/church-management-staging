# M+ 主題與舊工作介面移除

2026-10-20。依使用者要求，M+ 不再提供舊「我的工作」/協作平台入口；舊網址在確定 M+ 堂會後回到首頁。火樂路由保留，後端工作紀錄、送審工作及資料 API 未刪除。

首頁移除「管理工作」與舊工作卡片連結。共用行事曆讀取/新增、出勤請假與照片工具連結保留。行事曆文案拿掉 M+BOT。

M+ 的 head bootstrap 在繪製前選主題，停用 theme-vitality、apple-ui、church-palette 三套舊視覺皮膚；保留 auth.css、各功能自己的樣式和 app-consistency 語意規則，使用同一 M+ 色彩來源。沒有堂會識別的共用登入不推定堂會，明確 SHiNE 不套 M+ 主題。

驗證：13 項導覽/日期/主題隔離測試、18 項功能目錄檢查、22 項 service worker 檢查通過。瀏覽器驗證手機捲動後可用上方關閉鍵和底部取消，M+ 三套舊皮膚停用，SHiNE 零停用，首頁無舊工作網址，無水平溢出。未以實際同工帳號建立 Google 活動；iPhone 實機及所有功能端到端操作仍未全數驗收。
