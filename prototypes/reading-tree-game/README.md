# 讀經小樹：花園與全副軍裝互動示範

日期：2026-10-12。版本：20261012-game6。用途：先審閱美術、事件判斷、裝備操作與成長回饋。

## 開啟

- 在 Mac Safari 開啟同目錄 `preview.html`，保留旁邊的 `assets/` 資料夾。此檔已內嵌樣式及程式，無需安裝套件。
- `index.html` 為模組版入口，供網站伺服器提供此整個目錄時使用。
- 初始提供 7 天示範紀錄與 220 XP，可以體驗一次小樹升級。示範紀錄存在目前瀏覽器，正式系統紀錄不變。

## 已實作

1. 手繪花園、小樹、守護者、六件軍裝、開合裝備包與三種小黑影素材。
2. XP、等級、本級進度與下一階段門檻；達標立即顯示升級。
3. 打開裝備包、選取、取出、穿戴展示、使用、收回；所有軍裝可借用體驗。
4. 寶劍攻擊與黑影消散、盾牌抵擋火箭、護心鏡擦拭、祝福小徑、頭盔拼圖與真理行動選擇；提供點按替代手勢。
5. 每日六種不同事件、六件軍裝都要用到；普通日順序隨機，約 10% 為 Boss 日。Boss 日先完成腰帶、護心鏡與鞋的三項預備，再以盾牌、頭盔、寶劍回應三階段挑戰，各階段內部順序隨機。
6. 先讀事件，再從六件軍裝中選擇；拿錯顯示紅色叉叉與用途提示，可重試、不扣分、不進關卡、不發獎。拿對顯示勾號，仍須實際使用裝備完成事件。
7. 每日六種事件全部完成後，普通 +10 XP、Boss +30 XP；兩者互斥。重新進入保留當日抽選、事件順序、目前事件與使用進度。舊版已領獎日期保留獎勵，不重複領；未完成的舊版單一寶劍遭遇轉入新版六事件。
8. 讀經 +20 XP、澆水 +5 XP、選填手札 +5 XP；同日期只獎勵一次。每個從起始日計算的同行週，至少 5 個讀經日期 +30 XP。
9. 六種事件與 Boss 三階段的自由體驗入口，不改每日遭遇、不發 XP；方便逐一審閱拿錯與選對的流程。
10. 台北日期切換、鍵盤焦點、原生浮窗、音樂與音效各自開關／音量、減少動態效果、素材失敗重試與儲存不可用提示。

11. 首次進入選擇男生／女生，各三種外型；之後從表頭更換，保留所有示範進度與裝備。
12. 原創合成配樂隨場景變化：花園 76 BPM、事件懸疑 100 BPM、戰鬥 124 BPM、Boss 146 BPM；勝利音樂後回到場景。六件軍裝、開包、取出、選錯、澆水與 XP 各有操作音效。
13. 音樂／音效開關及音量分開保存；首次需點按啟動，離開前景暫停，經文朗讀降低音樂音量。瀏覽器阻擋時提供開始播放入口。

- 本版以獨立示範頁發布供視覺審閱；尚未取代正式讀經小樹。正式讀經計畫、登入、教會隔離及已有讀經資料沿用現有系統。

- 花園寶物先放在固定位置；自由布置與移動、正式收藏條件、每日完整經文仍待接入。

## 素材

`assets/garden-dawn.png`、`garden-atlas.png`、`garden-shadows.png`、`garden-avatars.png` 為此示範透過 imagegen 產生的專屬素材。透明素材以 SVG 範圍或背景定位顯示，沒有修改原始生成圖。`preview.html` 是由目前來源合併的便利預覽，修改來源後須重新產生。

角色素材提示詞與來源記錄見 `assets/asset-sources.json`。配樂是本專案以 Web Audio 編寫的原創旋律、和聲、鼓點與音效，未使用外部歌曲。實際揚聲器／耳機音色與 iPhone 中斷恢復待實機驗收。

## game5 小鳥與放置操作

同行小鳥改為專案自製 SVG：圓身、蓬鬆頭型、奶油色肚子、腮紅與小腳，背包、詳情與花園共用同一素材。保留原小鳥識別與已放置紀錄。

所有花園小物按「放進我的花園」後，保存示範狀態、關閉背包、焦點與畫面回到花園，以短暫亮光標示新放好的小物；尊重減少動效。收回小物保留背包開啟，方便繼續整理。

恩典小物的逐步收集屬待討論企劃：以累積完成讀經的不同日期為主，不花費小樹 XP、不因中斷沒收收藏。體驗版目前仍提供借用，尚未接入正式領取、收藏與伺服器紀錄。

## game6 角色服裝配色

男女角色各三色：森林綠、晴空藍、暖莓紅；披風、衣服與褲子搭配配色，保留原先臉型、髮型、姿勢與皮革／金色細節。使用 garden-avatars-v2.png，保留舊圖及原角色 id，換圖不重置已選角色、穿戴或成長。imagegen 編輯提示詞及來源見 assets/avatar-color-edit.json。
