# 教會 OS 第七批：排班長表單與實機驗收補查

基準：已發布的 `3f5e57ebbcb594af56f556ae4ea771388a612106`。本批程式尚未發布時，下列 Safari 及使用者 iPhone 結果只適用於當時的正式版。

## 長表單調整

實際 Mac Safari 的排班編輯器有二十多個人員欄位平鋪。本批將聚會資料與服事人員分區，加入服事項目／姓名搜尋及全部、尚未安排、已安排篩選；顯示目前已安排數與篩選結果數。編輯時維持目前欄位位置，避免輸入到一半跳動。篩選操作不標記業務草稿、不觸發儲存；選人後按 Enter 也不會意外送出整張表單。

人員建議選單補上方向鍵、Enter、Escape、Tab、對應選單識別與目前選項資訊，保留觸控／滑鼠選取與自行輸入姓名。手機打開編輯器先聚焦標題，不自動叫出鍵盤。既有日期以斜線保存時，轉為 date input 可編輯的 ISO 格式。

儲存仍收集所有已呈現欄位的值，包含被搜尋／狀態篩選暫時隱藏的欄位；另外帶回原紀錄中未呈現的固定欄位，避免編輯其他項目時清掉原值。自訂服事、原設定排序、堂會與既有儲存 API 保留。沒有修改資料庫、權限或通知設定。

週報既有雙軌分區與奉獻既有點收分區沿用，這批補做相關草稿、送審、錯誤及只讀恢復回歸。更新排班模組／CSS 引用與教會 OS shell cache 為 `20261022-experience7`。
