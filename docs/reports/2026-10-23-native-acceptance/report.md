# 原生 Safari 驗收與物品列印修正

日期：2026-10-23。來源：PR259 後的 `b2d906b88de5fb09e8b8310a48c991aef4f1a7dc`。本批先在本機完成，尚未發佈。

## 已完成

| 範圍 | 實際結果 |
| --- | --- |
| 原生 Mac Safari | 12 個固定情境通過，macOS／Safari 27.0.1。選檔取消、圖片預覽、上傳故障保留及重試、清冊與明細列印取消、排班鍵盤及副本下載。 |
| 清冊列印修正 | 新增清冊標題、單位、目前篩選與筆數；移除導覽、重新載入與編輯控制；保留使用者原搜尋。 |
| 明細列印修正 | 僅列印目前物品明細，移除背景工作區及編輯控制，解除浮窗高度與捲動裁切，保留借用／數量異動。 |
| 列印專項 | Chromium／WebKit 21 個檢查通過；涵蓋 M+、火樂、課輔空清冊。Chromium 另讀回兩堂會跨頁 PDF，核對30筆異動最後一筆完整輸出。 |
| 既有物品回歸 | 21 項通過，涵蓋320–1920px、200%文字、搜尋、編輯失敗重試、權限及單位切換。 |
| 固定回歸 | 15組全部通過，212個前端程式語法通過；42頁共1,485處文字對比檢查無失敗。 |
| 資源版本 | HTML、物品 CSS／模組及 Worker 同步為 `20261023-native1`。 |

這次不包含資料庫遷移、帳務操作或正式通知發送。原生上傳故障由本機合成回應產生，不能代表真實弱網路驗收。

## 尚待完成的驗收

- LINE：先前8位 M+ 同工的服務端送出已成功，實際收到與轉傳仍等待本人回覆；未重送。維持火樂不通知。
- iPhone：其餘鍵盤／選照片、LINE開啟返回、放大文字及 VoiceOver。前次主畫面發布頁未儲存修改、重新載入取消及背景返回已由使用者確認。
- 正式多人流程：不同角色審核、同時編輯、衝突恢復及真實弱網路。
- 原生 Safari 本批只執行這三個合成工作區；其他業務頁不能由本次結果推定通過。

上述仍待驗收，尚不能宣稱全系統達到99%。
