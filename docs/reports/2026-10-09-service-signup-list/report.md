# 服事登記清單與重新選擇流程

日期：2026-10-09。適用公開的 M＋服事登記頁。

## 已完成

- 已登記的會友進入後直接看到清單；表頭顯示已綁定會友名冊上的姓名及登記筆數，不使用 LINE 暱稱。
- 完成送出後收起姓名、服事類別、項目及日期的引導表單，顯示登記結果與清單。
- 季前刪除先確認刪除；成功後詢問是否重新選擇。選擇取消便留在清單，確認才重新開啟填寫流程。
- 季前修改只詢問一次是否重新選擇，清楚告知會先移除原登記；取消確認不更動資料。成功移除後才開啟表單，其他登記保留。
- 表單提供「返回我的登記」，最後一筆刪除後仍有具名空清單及重新選擇入口。
- 當季已開始時，調整與取消仍走服事領袖初審、鈺庭複審；審核前保留原登記，不直接重新選擇。
- 非同步操作鎖定控制項；完成或失敗恢復操作。操作已成功但清單刷新失敗時，只提供重新載入，不重送已完成的操作。
- 清單按鈕至少 44 × 44 CSS px，主要按鈕與輔助文字加深，保留公開頁核定的暖色與綠色品牌。

## 範圍與限制

本次修改前端清單及填寫動線，沒有修改資料庫、既有 LINE 登入或服事審核權限。季前修改沿用既有「先取消，再重新登記」機制，尚非保留原名額的原子替換；確認視窗會明確提示。

以上為 Mac 上 Chrome 與手機 viewport 模擬，iPhone 17、LINE 內開啟及 Mac Safari 本次尚待實機驗收；不據此宣稱整個系統已達 99%。
