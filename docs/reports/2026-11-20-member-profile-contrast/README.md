# 會友已綁定資料卡：閱讀對比修正

使用者回報帶出的本人資料卡為墨綠底，文字無法清楚閱讀。原卡片只在父層設定 text-white，church-palette.css 的全域 h3 顏色則直接套至姓名，未繼承父層白字；標籤另使用10px與低透明度。這種組合造成姓名深色壓在深綠漸層上、分類標籤偏淡。

將資料卡改為淺藍白底、深藍字，欄位白底，明確設定姓名、所屬小組、欄位名稱與內容的顏色，全部不使用文字透明度。卡片採局部樣式，避免全域標題規則覆蓋；CSS隨元件載入，不依賴外部Tailwind才能顯示清楚。保留所有欄位及四個可編輯欄位的原有提交行為，未更動API、權限或會友資料。

Chrome / WebKit ×375/393/430/1440，共8組合成資料檢查通過：實際 newcomer.html 及共用 church-palette.css 載入，姓名／小組／各欄位的計算對比最低7.09:1，最高11.56:1；生日可編輯、清空，放大文字後不溢出，儲存payload維持原欄位。Worker原有27項檢查通過。真實LINE手機尚待實機確認，不能以模擬結果宣稱全面驗收。

共用模組、入口與快取版本同步20261120-profilecontrast1；保留既有登入、綁定、待審及建檔流程。需要回退時，還原本次元件與入口版本並更新快取，不回復或刪除任何會員資料。

本修正與LINE選單視覺重做分開：前版選單仍僅牧師本人測試，亮色插畫收合式選單仍是材料預覽，沒有全體切換。
