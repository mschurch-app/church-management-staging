# 同工工作流程調查：改版需求基線

這份調查服務各種同工工作，包含課輔班、行政、總務設備、主日、敬拜影音、兒少與關懷。目的不是評核同工，而是收集實際的例行工作、容易漏掉的步驟、現有工具和希望的提醒，作為「我的工作」改版依據。

## 使用與資料邊界

- 已獲授權的教會 OS 或 LINE 同工身分可填寫；每人每單位每版本只有一份回覆，可以回來修改。
- 回覆存在 `pastoral_workflow_survey_responses`。瀏覽器不能直接查表；Edge Function 驗證身分、單位與角色後以 service role 操作。普通同工只讀自己的回覆；牧師／管理者只能看所屬單位的彙整。
- 問卷不建立任務、不推播、不傳送其他同工。發送連結與蒐集回覆由使用者決定。
- 管理者以回覆中的例行工作、工作頻率、提醒需求、阻礙及第一優先改善項來規劃改版，不把問卷答案當作工作表現評分。
