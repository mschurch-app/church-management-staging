# 教會奉獻與協會捐款獨立預覽頁

範圍：使用者要求先完成頁面並提供商店申請可用網址，不加入教會／協會網站導覽。金流商店另行申請，本次不啟用收款。

- 教會：`church-giving.html`；協會：`association-donate.html`。
- 使用共用設計 tokens、app-icons、app-ui 回饋。暖白與綠色教會配色、亮暖色協會配色；各自獨立組織標示及官網返回連結。
- 支持方式→收據資料→確認內容。單次四種付款選擇；定期預覽限定信用卡，LINE Pay 待預先授權申請。預計扣款日與期數明示為預覽選項。
- 金額整數檢查、姓名與 Email 檢查、單筆／年度／不索取收據、公開匿名選項。返回保留當頁輸入。確認頁明示尚未付款或授權，收款按鈕 disabled。
- 無 API、金流金鑰、資料庫、登入、排程或通知變更。不使用 localStorage/sessionStorage/cookie 儲存表單，不建立訂單或授權。無分析追蹤。所有動作按鈕 type=button，form submit 被阻止。
- noindex/nofollow、no-referrer。只以獨立網址預覽，不新增官方網站導覽、LINE 入口或現有奉獻查詢連結。OS 目錄登錄 owner-only 預覽 metadata，不授予財務能力或開放收款。
- 共用模組版本未變更，因其行為未修改；新頁面資源使用 `20261120-giving1`，不接入 App 快取或更動 Worker。正式支付整合前重新驗收。
