# 信息預備：三輪引導查找

M＋同工在「信息預備工作室 → 素材」可開始三輪勾選問答。第一輪從草稿主題、經文、對象與筆記出題；第二、三輪由 Mini 本機模型依先前答案追問。每輪可複選，至少選一項；第三輪送出前不查詢或顯示候選信息。第三輪後才從 QNAP 私人資料庫按模型提出的主題詞查找，按符合主題數與來源狀態排序，每個來源頁面只列一段，最多六筆。候選段落保留原始連結、可能講員與內容指紋，加入草稿前仍須回查上下文並由同工勾選核對。

引導進度由既有私人工作佇列保存，重新開啟專案可接續已完成題目；進行中顯示等待，失敗可從上一題重試。關鍵字搜尋保留在折疊區。草稿、權限、版本與 NAS 備份流程沿用原工作室；引導勾選不會額外建立草稿版本，也不會發布信息。

後端沿用既有 M＋週報編輯權、LINE 綁定、JWT、owner 隔離與 Mini 私人憑證。下一輪由服務端讀回前一筆已完成工作並重建答案歷史，拒絕跨專案、跳輪、空答與重複選項。資料庫只新增 `guide` 工作類型，供原本的 model lane 領取；不開放瀏覽器直連 NAS 或模型。

驗證：11 項 Node 契約測試與 10 項 Python worker 測試通過；隔離瀏覽器走完三輪，候選來源只在第三輪答案後出現。Mac mini 本機 Qwen3-4B 模型以合成資料成功產生第一輪問答；正式 Edge Function v4 ACTIVE 且未帶登入的提交回 401。正式同工帳號的完整三輪與真實 QNAP 候選內容、iPhone 17／LINE 內開及 Mac Safari 實機仍待驗收，不宣稱 99%。
