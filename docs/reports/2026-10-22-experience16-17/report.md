# 教會 OS 第十六、十七階段：每日靈修裝置續填與副本

基準：已發布的 #247，主分支 `4a4e05b975d314ef32c5a94ed472b2e0784bf9d5`。接續第十一批明列的「靈修編輯僅保留目前頁面」未完成項；本輪兩階段合併交付。本機完成，尚未發布。

## 第十六階段：每日靈修裝置草稿

- 沿用既有每日靈修工作區及 M＋生命樹管理／核准權限；編輯者可主動選擇保留一份裝置草稿。同一瀏覽器／App、同一次登入可在 24 小時內續填，共用裝置不建議開啟。
- 輸入經防抖與序列寫入保存於 IndexedDB；頁面隱藏／離開時嘗試處理待寫入內容，不宣稱系統強制終止前一定完成。未開啟保留時不存本機草稿。
- 重載後先提供日期、標題與時間供核對，不自動套用。恢復重新驗證伺服器使用者與目前管理權限，並比對正式紀錄的 id、日期、版本、狀態與全部可編輯內容；已變更或刪除時拒絕套用，保留本機副本。
- 恢復後仍標記為未儲存，正式按鈕維持「儲存並直接核准」。缺少必填欄位的草稿可保留／續填，正式送出仍要求原有 8 個必填欄位；3 個聖經版本／授權欄位維持選填。
- 啟用／恢復的草稿正式送出前再次核對登入及正式內容；既有後端核准規則與 API 保持相容。明確保存成功才清除該份副本；回應不明時保留輸入並禁止重複送出。
- 本機 revision 防止其他分頁副本被靜默覆寫。儲存空間不足及 IndexedDB callback 例外均回報失敗並保留本頁輸入；登出隱藏編輯內容並清除這次登入的本機副本。延遲 API 回應以登入世代檢查防止登出後重建舊內容。
- 第一階段以本機提交 `1231461` 保存，再接續副本功能。

## 第十七階段：靈修草稿檢視與下載

- 裝置草稿及正在編輯的本頁內容均接入既有唯讀副本浮窗，可全選文字、下載 TXT 或完整 JSON。日期、來源及「未送出」狀態清楚標示；不自動合併、匯入、核准或通知。
- 開啟及每次下載都重新驗證管理與匯出權限；裝置來源另查 revision／期限，本頁來源另查目前紀錄與內容。登出、權限撤回、來源被替換／到期與取消期間的延遲回應均不產生下載。
- 正式內容已變更或刪除，仍可取回本人同次登入的既存有效裝置副本，供人工比較；原恢復檢查不因此放寬。
- 僅收錄 11 個已知內容欄位、日期與副本來源，不加入登入、session、本機 key、revision、原正式內容指紋等識別。未知欄位或過長內容拒絕處理；內容以 textarea value 顯示，HTML 字串不會執行。
- 正式保存成功、但另一分頁已更新副本而無法清除時，保留較新的副本並提示重新載入核對，明確要求勿重複送出。
- 沿用共用 dialog 的 Escape、背景捲動鎖定與焦點還原。手機動作兩欄、至少 44 CSS px，根字級放大可繼續操作；未新增全域視覺覆寫或首頁功能入口。

專項以本機合成 API、固定合成登入及真實 IndexedDB 驗證；瀏覽器外部請求攔截。Mac Safari 也只使用本機合成 fixture。沒有正式業務寫入、AI／NAS 工作、LINE 或第三方通知。固定清單中的寫入均為合成 mock。

失敗與修正：起初未指定既有 WebKit 路徑及本機伺服器沙箱權限，修正執行環境後重跑。儲存額度模擬發現非同步 IndexedDB callback 例外未被完整攔截，補上 transaction abort 與 Promise 失敗處理，原門檻重驗通過。第一次副本文字檢查發現缺少預期「未送出」標示，補齊介面文字後通過。第一次固定 gate 的依賴連結缺 PGlite，保留失敗紀錄，改用符合鎖檔的 PGlite 0.3.14／puppeteer-core 25.12.0 後完整通過；補上清除副本衝突的真實回饋後，再以最終程式完整執行固定 gate。沒有降低或刪除失敗斷言。

## 限制與後續

- 僅保留一份、同次登入、同一瀏覽器／App 的裝置草稿。24 小時到期於下次存取／清理時刪除，沒有背景定時刪除保證；未使用額外加密。無法保證 OS 強制終止前未完成的 IndexedDB 寫入，不能當作伺服器備份。
- 正式內容核對是用戶端快照比對；既有儲存 API 沒有追加原子版本條件，最後一次讀取與正式保存之間仍有多人同時編輯的競爭窗口。下一批可評估配套後端條件式版本保存與隔離 SQL 驗收，本輪沒有改變資料庫／RPC／後端 API。
- 開啟／續填／下載需要連線確認當前權限；離線不直接公開或排隊送出資料。失去權限時拒絕新操作，已在瀏覽器出現的內容仍受既有前端驗證時間窗限制。
- Mac Safari 原生下載入口出現網站下載授權提示，本輪取消，沒有變更下載權限或宣稱檔案已落地；Chromium／WebKit 則實際讀回 TXT 與 JSON。
- iPhone 17 主畫面 App／Safari／LINE 入口、實體觸控與鍵盤、螢幕閱讀器、弱網與正式多人完整流程仍待驗收。沒有宣稱全站實機 99%。
- 依 Supabase 技能核對 [getUser](https://supabase.com/docs/reference/javascript/auth-getuser)、[Auth 訂閱](https://supabase.com/docs/reference/javascript/auth-onauthstatechange) 及 changelog。沿用 readAccess 的伺服器使用者核對，不用 user_metadata 授權；Auth callback 同步失效、排入本機清除，不等待 Auth 方法。未升級 SDK、修改 RLS、資料表、Storage 或通知規則。
- Worker 最終版本為 `church-os-shell-20261022-experience17`，新增六個版本資源，共 80 個去重快取項目；共用副本資源沿用 experience14。發布後仍需核對正式來源及實際快取。
