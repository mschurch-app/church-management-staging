# 相簿權限

帳號與權限 → 同工帳號 → 設定 → 內容、通知與設定 → 相簿。

新增獨立的查看、新增資料夾、上傳照片／檔案勾選項，適用教會、課輔兩個主相簿與子資料夾。移除相簿入口對「同工工作」模組的依賴。既有有效同工的操作權在遷移時保留，新同工須由擁有者授權。

後端每次使用已驗證的同工身分查詢權限，先檢查操作權，再取得 Google 存取權。建立與上傳仍需 Google 資料夾可寫入，保留根目錄邊界檢查。權限查詢 RPC 僅允許 service_role，瀏覽器無法傳入任意同工身分查詢。

驗證：後端及導覽 17 項測試通過；393px、1440px 合成瀏覽器測試涵蓋兩類資料夾、子資料夾、照片分區、批次上傳、無橫向溢出及權限勾選輸出。正式資料庫確認指定四位同工可新增資料夾。未宣稱 iPhone 實機驗收。

發布：PR 302 已合併，GitHub Pages 發布成功；正式 HTML、權限控制模組與 Worker 版本已讀回確認。未登入直接呼叫建立資料夾回應 401。

補充檢查：251 個前端檔案語法檢查通過，Worker／目錄／metadata 的指定品質檢查通過。完整歷史測試套件仍有未安裝的 puppeteer-core 等相依套件，因此未宣稱全站完整品質門檻通過。角色建議的測試改為比較內容，避免不同版本模組載入時把相同資料誤判為不同物件。
