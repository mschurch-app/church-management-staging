# 教會 OS：五個內容工作區優化

日期：2026-10-23。此報告記錄本機完成與驗收結果；尚未發布。

## 五階段

| 階段 | 工作區 | 改善 |
| --- | --- | --- |
| 1 | 給今天的你 | 桌面清單／編輯並排、手機單欄；搜尋與分頁保留草稿；修正儲存後忙碌狀態未解除。 |
| 2 | 把愛傳出去 | 圖片、經文與祝福內容分區；情境管理與圖卡編輯一次開啟一個；新增情境、取消與切換具草稿保護。 |
| 3 | 牧養圖卡 | 祝禱範本與新朋友旅程加入內容搜尋、結果摘要、明確選取狀態與並排編輯。 |
| 4 | YouTube 字幕詞庫 | 詞彙卡片網格；啟用中待確認／已確認篩選；保留目前集數；手機浮窗、Escape 草稿確認與視窗內重新載入。 |
| 5 | 協會最新消息 | 最近 20 則已發布主題搜尋、桌面清單與表單並排；修正清空方法與按鈕撞名；確認發布後清空表單，再重新讀取清單。 |

三個內容庫同時驗證 M+ 與火樂。字幕詞庫與協會消息維持原有 M+ 範圍。M+ 使用深綠 `#173f34`、火樂使用磚紅 `#a83929`；卡片、徽章、表單、導覽選取與狀態回饋沿用共用語意色。

## 儲存與恢復

`content-workflow.mjs` 沿用既有草稿／控制鎖定工具。取消、換筆、清空與重新載入先確認未儲存內容；清單篩選保留編輯。操作進行中鎖定控制，重複點擊只送出一次。

已確認寫入與後續清單更新分開處理。清單讀取失敗不要求再次新增或發布；缺少回傳確認、網路結果不明時停用再次送出，提供重新載入。教牧內容保留原先堂會條件及 RLS，協會消息新增以回傳一筆 id 確認。登入失效會清除內容，忽略先前尚未返回的請求。

本批沒有資料庫遷移、後端部署、通知路由或 LINE 發送變更；正式資料寫入為 0。草稿保護是目前頁面的離開確認，不代表關閉 App 後的持久恢復。

## 驗證結果

- **1,056 項隔離檢查通過，0 失敗**：Chromium／WebKit、390／1440 CSS px，共 32 組頁面環境。
- 每組包含清單與編輯畫面、164 px 表頭、44 px 表單控制、文字對比、200% 根字體、取消／換筆草稿、寫入失敗、重複點擊、成功後讀取失敗、結果不明、權限拒絕及登出後晚到回應。桌面另檢查 1280／1920 px。
- 三個內容庫採實際教牧資料管理模組，資料庫與身分服務以合成資料替代。字幕 API、協會發布與圖片儲存均隔離；未對正式服務寫入。
- 固定 **15 組驗收通過**；209 個前端程式語法通過，最後 7 個變更程式另行複核。
- 初輪修正：協會表單 `reset` 方法被同名按鈕遮蔽、WebKit 長講題選單溢出、舊導覽漸層對比不足。對比修正後完整 42 頁重跑通過。
- 全套 1,056 項通過後，僅調整字幕手機浮窗寬度與內距；該頁四組環境的 **124 項**重跑通過並取代先前同項結果，沒有重複加總。
