# 生命樹八套節慶互動預覽

## 交付範圍

使用者核准完整節慶企劃後，執行第一個交付：八套可試玩的手機與桌面場景。追加要求「12月的樹要佈置聖誕燈與裝飾」納入整個12月，與聖誕週活動分開。

此輪為公開、無個資的互動預覽與可重用日曆／美術模組；不是已啟用的2027正式活動、資料庫收藏或活動管理後台。正式2027讀經入口屬另一專案，未將預覽狀態接入其使用者紀錄。正式活動需後續接入已驗證身分、實際澆水完成結果、本人收藏、防重送、內容審核與既有單一靈修手札。候選經文默想未視為已核准；無通知發送。

| 場景 | 明確主意象及動態 |

| 端午節 | 粽子、粽葉、龍舟與同步划槳 |
| 中秋節 | 大圓月、月光倒影、家庭野餐與燈籠 |
| 光明勇士 | 七隻具名暗影怪與七種對應裝備；三次互動、光束與小怪退場 |
| 感恩節 | 火雞、南瓜、麵包、餐桌與家人；落葉、火雞動作及餐桌漸次豐富 |
| 聖誕節 | 馬槽、嬰孩、父母、天使、牧人與羊、引路星光 |

聖誕整月：12/1～12/31保留三層燈串、19顆錯開閃爍的燈泡、五顆彩球、蝴蝶結、樹頂星星與禮物；12/20～12/26才進入完整聖誕週馬槽情境。可用 `?date=2027-12-05` 與 `?date=2027-12-25` 分別檢查。日曆目前明確限定2027，不推定其他年份農曆節日。

每套七天各有經文出處、原創默想與手札提示，共56組候選內容。日期選擇表示預覽當天的場景階段，收藏只計本次實際完成的七天；快速切換、重看及重複點擊不重複計數。收藏重新整理即清空，唯聲音與減少動態偏好可留在瀏覽器。連往既有一月每日靈修試閱，標明試閱月份，沒有新增第二份手札。

美術為自製分層SVG，非外部圖片、下載素材或AI點陣圖。手機樹圖下方放主要操作，桌面以花園／任務雙欄呈現；喇叭為表頭44px圖示。尊重系統減少動態，亦有手動開關，背景暫停動畫和音樂。八首原創音樂只按需載入當前曲目；播放失敗可重試，保留已同意聲音者的一般輕觸恢復途徑。

## 系統接入

- `life-tree-festivals.html`、`.css`、`life-tree-festival-preview.mjs`：公開隔離預覽，無LINE、Supabase、資料服務及真實進度寫入。
- `life-tree-festivals.mjs`：八個活動、56組候選內容、日曆及整月聖誕裝飾判斷。
- `life-tree-festival-art.mjs`：SVG場景、徽章及七種裝備。
- 新metadata `life_tree_festivals`：M+、既有生命樹管理權限（仍需members搭配）、內容與發布分類，設定與工具可找到。`configurableHome:false`，沒有擴充伺服器首頁偏好或授予權限。
- 共用definitions直接引用統一 `20261010-festival1`，Worker shell版本同批更新；不清除登入。共同圖示模組僅更新definitions引用，圖示內容不變。

## 固定驗收與證據

隔離瀏覽器以Mac上的Chromium進行；viewport320、402、760、1024、1280、1440、1920 CSS px。包含八套主意象、聖誕整月／週差別、56天完成、重複提交、切換取消、收藏、防重複、圖外操作、44px、浮窗焦點、音樂阻擋／逾時／重試、減少動態、頁面返回與零資料服務請求。47項全部通過，詳見同目錄 `results.json` 與截圖。

第一次完整品質門檻因缺少本機測試套件（11組未能執行）未能完成；安裝鎖定依賴後重跑。第二次發現舊回歸硬編碼41個功能，依新增一個預覽入口更新為42；保留失敗摘要並重跑。手機日期鈕初測寬度不足44px，改為四加三排列，寬桌面維持七顆一排。

共用品質門檻的15組測試與121個前端語法檢查，各自最後結果均通過（`gate-effective.json`彙整兩次執行；原完整指令曾因舊41項斷言exit 1，修正後phase2由同一gate補跑exit 0，原失敗證據保留）。

Mac Safari、真實iPhone 17與LINE內播放／觸控仍待實機驗收；不宣稱99%。正式登入、資料服務及原十月生命樹由既有隔離回歸另外確認，預覽本身不呼叫正式服務。
