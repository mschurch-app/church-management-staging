# 教會 OS：場地、設備、物品、關懷與教材五階段優化

日期：2026-10-23。此報告記錄發布前的本機驗收；正式上線以 PR 與部署結果為準。

## 範圍與設計理由

這批接續已發布的會友與關懷管理工作區，把相同介面規範延伸至五個尚未整理的工作頁。

| 階段 | 頁面 | 完成項目 |
| --- | --- | --- |
| 1 | 場地預約 | 空間、申請人與用途搜尋；預約狀態篩選；最近 100 筆範圍提示；清單與編輯區並排；台灣日期與時間順序檢查。 |
| 2 | 設備管理 | 名稱搜尋、使用中／停用切換與數量摘要；獨立編輯區、清除篩選與讀取重試。 |
| 3 | 物品與借用 | 可用數量、安全庫存、待處理篩選；清除篩選與重新載入；浮窗草稿、送出鎖定、晚到明細與權限恢復保護。 |
| 4 | 關懷訊息 | 狀態統計、清單與內部紀錄並排、最近 200 筆範圍提示；背景遮蔽、返回重新確認權限，保留草稿。 |
| 5 | 小組教材 | 日期與公開狀態摘要、搜尋／狀態篩選；清單與內容區分離；新增、修改及刪除回報實際回傳紀錄，更新限定堂會與內容類型。 |

共用 `operations-workspace.css` 沿用既有語意色、品牌、系統字體、164 px 表頭與 44 px 操作尺寸。手機採單欄，桌面依工作內容並排。新增 `operations-workflow.mjs` 使用既有草稿與控制鎖定工具，避免五頁分別處理而出現不一致。

儲存失敗保留輸入；確認已儲存而刷新失敗時，清除舊的可操作清單並提示重新讀取。連續點擊只執行一次表單操作。無法確認的結果提示先載入核對。登入改變會清除編輯與資料，忽略尚未返回的舊請求。

本批沒有資料庫遷移、後端部署或通知路由變更。關懷備註繼續只儲存內部紀錄。

## 驗證

- 新增隔離瀏覽器檢查：**868 項通過，0 失敗**。
- Chromium 與 WebKit：390／1440 CSS px；四頁各測 M+／SHiNE，小組教材依既有範圍僅測 M+，共 36 組頁面環境。
- 每組檢查清單與編輯畫面、文字對比、44 px 控制、164 px 表頭、200% 根字體、資料讀取／寫入失敗、取消切換草稿、重複送出、刷新不重送、撤銷權限、登出後晚到資料。桌面另驗 1280／1920 px。
- 關懷訊息另測背景遮蔽與返回保留草稿；場地另測時間順序；教材另核對寫入堂會與內容類型；物品另驗可用狀況篩選。
- 既有物品回歸：**21 項通過**，實際 Supabase 客戶端對隔離 API，涵蓋 320–1920 px、鍵盤、編輯失敗重試、唯讀角色、單位切換、列印呼叫及無外部請求。
- 固定 **15 組回歸全部通過**；208 個前端程式語法檢查通過，最終新增／修改模組另行複核語法。摘要見 `quality-gate.json`。
- 實際正式資料寫入、LINE 發送、對外上傳與部署：**0**。

瀏覽器測試使用合成服務與資料；既有物品回歸保留實際 Supabase 客戶端。公開物品回歸報告僅保留結果與模擬寫入次數，省略請求內容與識別碼。兩者皆不能代替正式資料庫多人驗收。首次固定清單因本機 8769 伺服器未運作而中止；恢復伺服器後重新完整執行。測試發現並修正了分類／教材摘要／浮窗標籤對比不足；物品測試也修正把本機內嵌 SVG 誤判為外部請求的判斷。
