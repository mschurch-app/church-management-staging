# 週報 Canva 選圖狀態修復（2026-10-21）

正式版 radio change 呼叫 sync → renderJob → renderOptions，重建選項時沒有恢復 checked，導致剛選的圖立即取消；隔離瀏覽器在修復前穩定重現。修復讓一般狀態同步保留原節點與鍵盤焦點，重載批次時以完整「工作 ID:設計編號」保留選擇。整張預覽放進原生 label，照片亦可點選，並提供選取邊框。

新版兩頁籤原本已傳完整選項值；一併修正舊 wizard 路徑，避免 Number 將完整值轉成 NaN。套用時嚴格核對批次和 1–3 設計編號，不再默默套用最後一批或第一款。下載失敗停止進度，保留原圖與選擇；只讀仍不可編輯。

HTML、Canva 模組與 CSS 更新查詢版本，App 快取版本同步更新，維持使用者主動更新機制。沒有重新產生 Canva 圖片、修改週報資料或寄送通知。

本機 Chrome 隔離假資料：桌面 1280×900 與手機尺寸 390×844 共 14 項通過；既有 Worker 回歸 22 項通過，合計 36 項。包含選取、同步、點圖片、鍵盤、跨批次兩尺寸套用、重載、失敗恢復及只讀。真實 iPhone／Safari、正式登入與真實週報保存待實機驗收；不宣稱99%。
