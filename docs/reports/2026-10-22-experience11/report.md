# 教會 OS 第十一批：每日靈修長表單操作

基準：已發布的 `9b6b77850061e9cf715222a1cc0145a17c794e23`（#243）。接續既定「長表單分區、選填標示、欄位錯誤定位與失敗恢復」項目，把第八批的共用欄位提示推廣至每日靈修工作區。

## 改善內容

- 編輯器顯示目前日期，提供「經文與出處／聖經版本與授權／靈修內容」三個區段入口；可用觸控或鍵盤直接跳到區段。入口只移動焦點，不送出資料、不標記未儲存修改。
- 編輯時暫時隱藏同篇原文預覽，避免原文與編輯欄位重複堆疊；取消後回到原文及編輯按鈕。取消經確認後會清除過期錯誤訊息，顯示原本已儲存內容仍保留。
- 經文版本、來源與授權說明明確標示「選填」。原有八個必填欄位、直接核准及經文授權未齊不公開等規則沿用。
- 空白、只有空白字元及超過原欄位長度的內容，在送出前一次列出。錯誤清單可點選跳到欄位，搭配欄位旁說明、`aria-invalid` 及 `aria-describedby`；修正時移除該欄舊提示，不誤標伺服器錯誤為必填問題。
- 沿用第八批 `form-guidance.mjs`／CSS，未修改共用模組。標題與經文出處上限仍為 300、其他欄位 5,000；超長既有或程式帶入內容會先要求修正，避免直接送往後端後被裁切。
- 手機／粗指標開啟編輯時先定位到編輯標題，桌面維持第一欄輸入焦點。這是瀏覽器焦點行為；是否實際彈出 iPhone 鍵盤仍須實機驗收。
- 靈修頁沿用共用系統字體；區段與錯誤按鈕至少 44 CSS px，輸入至少 16 px，200% 文字時跟隨根字級放大。樣式限於靈修工作區。

四個執行檔為 `daily-devotional-admin.mjs`、CSS、HTML 及 Worker。靈修模組／樣式引用與 shell cache 一致更新至 `20261022-experience11`，保留原排班草稿及其他功能的既有資源版本。沒有資料庫、API、登入、權限或通知規則變更。
