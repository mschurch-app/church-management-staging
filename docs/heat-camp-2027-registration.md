# 2027 熱火籃球營報名系統

## 系統邊界

本系統為獨立的營會報名、付款與收據流程，不讀取、不寫入，也不以外鍵連結既有籃球隊球員系統。教會 OS 只提供授權同工進入營會管理後台的入口。

## 活動設定

- 活動日期：2027/07/12–07/15
- 活動地點：台中東海大學
- 名額：100 名
- 球衣自選截止：2027/06/30 23:59（台灣時間）
- 名額成立：藍新回傳付款成功後正式成立
- 暫留名額：取得虛擬帳號後保留 72 小時；逾期未付款自動釋出

## 球衣背號防呆

- 報名頁以選單顯示 0–99，只回傳尚未被有效報名占用的背號。
- 已送出、例外待審、友情價待配對、待付款及已付款的背號都不再出現在選單。
- 取得付款帳號後保留 72 小時；付款期限屆滿且未付款，系統取消保留並重新開放背號。
- 送出報名時由資料庫唯一索引再次檢查。兩人同時選到同一號碼時，只接受第一筆成功鎖定的資料，第二筆會立即取得新的可選清單。
- 已付款背號永久鎖定；取消或退款是否釋出，由營會管理員決定。

## 價格規則

價格必須由伺服器依台灣時間判斷，前端只顯示預估金額。

| 方案 | 每人 | 適用條件 |
| --- | ---: | --- |
| 2026 現場優惠 | 6,000 | 僅限持有工作人員核發之一次性驗證碼 |
| 跨年早鳥 | 7,000 | 2026/10/01–12/31 |
| 新年優惠 | 8,000 | 2027/01/01–03/31 |
| 晚鳥優惠 | 9,000 | 2027/04/01–05/31 |
| 原價 | 10,000 | 2027/06/01 起 |
| 熱火友情價 | 8,000 | 2027/01/01–06/30；兩位資料都完成後才成立 |

友情價由第一位建立同行代碼，第二位輸入代碼完成配對。配對前不產生付款帳號；配對後兩人各有獨立藍新訂單與虛擬帳號。

## 報名狀態

1. `draft`：資料已收到，尚未完成資格檢查。
2. `exception_review`：國小六年級以下提出例外申請，等待同工審核。
3. `awaiting_pair`：友情價等待第二位完成資料。
4. `awaiting_payment`：已取得藍新虛擬帳號，保留名額 72 小時。
5. `paid`：藍新通知付款成功，正式佔用名額並排入思遠匯入。
6. `waitlisted`：100 名已滿，依付款資格與時間候補。
7. `cancelled`／`refunded`：取消或退款。

## 年級資格

- 表單同時收集生日與「營會當時就讀階段」。
- 選擇國小六年級以下時，不能直接付款；必須勾選例外申請並填原因。
- 同工核准後才可產生藍新付款帳號。
- 生日與年級明顯不一致時標記給同工人工確認，不以生日推算取代家長填寫的實際學籍。

## 藍新金流

- 每一位球員各自建立 `MerchantOrderNo`，即使是友情價也不共用訂單。
- 支付方式開啟信用卡與 ATM 虛擬帳號；金額與品名由伺服器帶入。
- `MerchantID`、`HashKey`、`HashIV` 只存於 Supabase Edge Function secrets。
- 取號結果保存銀行代碼、到期時間與遮罩帳號；完整帳號加密保存。
- 付款成功只採信藍新背景通知，驗證回傳資料、商店代號、訂單編號與金額後才更新為 `paid`。
- 重複通知以訂單編號及交易序號去重，確保不會重複入帳或重複開收據。

## 思遠捐款平台收據流程

付款成功後建立一筆不可重複的匯入工作，目標項目固定為「2027年籃球營」。

### 匯入格式

已依思遠提供的 `orders_upload_2026-10-06.xls` 完整範本設定：

- 工作表名稱：`orders`
- 付款方式代碼：藍新信用卡為 `1`、ATM 虛擬帳號為 `3`
- 籃球營項目編號：`172`
- 是否需要收據：`2`（印製收據）
- 金額：藍新實際入帳金額
- 數量：`1`
- 日期格式：台北時間文字 `YYYY-MM-DD HH:mm:ss`
- 國稅局上傳：家長同意時為 `1`，未同意為 `0`
- 完整維持範例檔 25 欄的欄位名稱、順序、工作表名稱與舊版 `.xls` 格式

### 匯入欄位

| 思遠欄位 | 報名系統來源 |
| --- | --- |
| 捐款人姓名 | 家長／監護人姓名，表單可另行修改 |
| 手機 | 家長手機 |
| Email | 家長 Email |
| 地址 | 收據寄送地址 |
| 捐款項目 | 2027年籃球營 |
| 金額 | 藍新實際入帳金額 |
| 捐款日期 | 藍新付款完成時間 |
| 付款方式 | 依藍新實際付款方式帶入信用卡或 ATM 虛擬帳號 |
| 管理者備註 | 報名編號、藍新 MerchantOrderNo、藍新交易序號 |
| 收據方式 | 單筆／年度／不索取 |
| 收據抬頭 | 家長填寫的收據抬頭 |
| 收據 ID | 家長填寫的身分證字號或統一編號 |
| 備註 | 報名編號、球員姓名 |
| 徵信姓名 | 依家長是否同意公開 |

球員保險用身分證字號、生日、健康資料、特殊身分與球衣資料不得傳入思遠平台。

### 串接策略

1. 若思遠提供正式 API：付款成功後由伺服器排程呼叫，外部單號作為冪等鍵；失敗採延遲重試，成功保存思遠紀錄編號及收據編號。
2. 若思遠只提供後台批次匯入：系統每日產生符合其格式的加密 CSV；財務同工下載、匯入後回填批次編號。已匯出資料不會再次出現在下一批。
3. 若只有人工新增：後台提供「待開收據」清單與逐筆複製欄位，並保留完成註記。此方式只作臨時備援。

## 後台首頁

- 即時數字：已付款、待付款、例外待審、友情價待配對、剩餘名額、思遠待匯入。
- 報名清單：依球員、家長、手機、報名編號搜尋；預設遮罩身分證與敏感健康資料。
- 付款對帳：虛擬帳號已取號、已付款、已逾期、金額不符與通知錯誤。
- 收據作業：待同步、同步中、已匯入、失敗、可重送；顯示思遠收據編號。
- 匯出：保險名冊、住宿餐食、球衣製作、財務對帳各自輸出必要欄位，避免所有資料混在同一份檔案。

## 權限

- 報名同工：一般資料、資格審核、友情價配對。
- 財務同工：付款及思遠收據資料。
- 保險承辦：一次性匯出投保必要資料。
- 醫護／帶隊主管：經授權查看健康與照顧資訊。
- 系統管理員：設定價格、名額、截止日與外部串接，不預設顯示完整身分證。

所有檢視、解密、匯出、重送與狀態修改都寫入稽核紀錄。
