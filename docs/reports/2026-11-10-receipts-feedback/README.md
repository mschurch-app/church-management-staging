# 收據儲存回饋與列印入口修補

使用者回報新增收據按儲存後完全沒有回饋，也找不到可列印項目。原生表單驗證可能在 submit handler 前攔截，頁面未提供明確的缺漏欄位說明。新增頁面可見的驗證訊息、儲存中狀態與儲存成功後的下一步；清單增加草稿預覽及正式收據列印入口，保留後端的列印權限檢查。

## 驗證

- 28 項既有資料庫、收入分類、權限、編號、匯出及 Edge Function 測試通過。
- 新增 Chromium / WebKit × 393 / 1440 CSS px 的合成流程：缺欄位不送出、有回饋；儲存中；失敗保留輸入；重試儲存；草稿預覽；確認開立；呼叫列印；物品無估值儲存。四種環境全數通過。
- 既有專案／事工介面回歸同四種環境通過。
