# 首次例行工作只設定一次

要求：同工完成首次例行工作設定後，再次登入不自動跳出。

原因：原流程只有按最後的「結束設定」才保存完成旗標；完成狀態又限定單一發行 campaign。儲存後直接關閉的帳號容易被再次要求設定。

修改：確認 Google 寫入與例行工作狀態成功後，立即保存操作者帳號的完成旗標。狀態讀取接受同一帳號歷次完成紀錄；既有自己建立的 active/stopped 例行工作也代表已設定，無須重做。別人的工作、協作身分、尚未確認成功的 pending 工作不代表本人完成設定。明確選擇目前沒有例行工作亦會保存。關閉空白畫面不冒充完成；例行工作入口仍可調整。

基準為正式 Edge Function v43，保留已部署的全天日期、權限與工作用語修正，對齊 repository 原本落後的來源；此次部署僅新增設定持久化判斷及保存，其他部署檔逐一沿用 v43。

驗證：Node 隔離資料 25 項通過，含首次儲存即完成、舊版旗標跨版本有效、舊有 active/stopped 免重做、pending/失敗不誤判、帳號隔離及跨日新請求。沒有以測試新增正式工作或寄送通知。未修改登入、RLS 或資料結構。iPhone 與 Mac Safari 實機仍待使用者操作驗證，未宣稱整體 99%。
