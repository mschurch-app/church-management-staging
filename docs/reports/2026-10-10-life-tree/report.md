# 生命樹讀經操作與靈修試閱修正

日期：2026-10-10。範圍：目前同工使用的十月箴言測試頁及現有一月靈修預覽。

## 完成內容

- 音樂入口移到頁面上方，個人／小組／教會視角均可操作。依實際 AudioContext 與播放 timer 顯示「播放音樂／正在開啟／暫停音樂」；保留開關偏好，啟動失敗顯示重試，進入背景停止排程。沒有更換原本合成的旋律。
- 「重新整理進度」接上原有 API；讀經、補讀、澆水、挑戰、手札增加等待回饋及防重複送出。失敗恢復操作並保留輸入。
- 縮短宣傳區，加入首屏今日讀經入口；挑戰與排行可收合，有未完成挑戰會自動展開。花園及排行按需要載入，切換回應不覆蓋更新的選擇。
- 花園按可用寬度分列；主要控制至少44 CSS px高。桌面保持完整生命樹比例；手機保留安全區域。頁面動效遵守減少動態效果設定。
- 沿用 `tree-reading-preview.css` 與原本繪本插畫，新增僅限 `.october-journey` 的樣式，不改管理介面配色或其他頁面全域按鈕。
- 共用經文載入器加15秒期限，失敗清除快取，頁面提供重新載入。這個共用變更只影響使用此載入器的經文請求，不改經文內容、讀經範圍或紀錄契約。
- 今天澆水成功後顯示「體驗每日靈修 / 與神相遇」。導向既有2027/1/1創世記試閱；不寫靈修完成紀錄，不修改十月進度。固定返回箴言頁，保留返回位置及同一身分的當頁手札草稿；一般靈修入口仍返回會友服務。
- 更新兩頁資源版本及該頁的載入器版本；兩頁沒有新增 App Service Worker 或後端依賴。
