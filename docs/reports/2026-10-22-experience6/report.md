# 教會 OS 第六批：首頁載入與服事操作順序

## 本批調整

- M+ 首頁在確認堂會權限後，同時讀取首頁偏好、堂會設定、系統監控、功能能力及財務入口權限，減少等待串接。所有原本的權限判斷仍在資料返回後執行。
- 同工帳號頁同時讀取名冊與待審 LINE 申請；名冊先呈現，申請區保留載入與失敗重試。申請 RPC 仍由後端驗證權限。
- 服事排班頁先顯示本週與未來服事、編輯入口和載入狀態，再顯示分享圖與服事項目設定，讓手機使用者較快找到主要工作。
- 週報與講道審核頁的多張候選圖片改為延遲載入、非同步解碼，降低初次開頁同時下載圖片的壓力。
- 更新 HTML 模組引用與教會 OS shell cache 版本，避免已安裝 App 沿用舊模組。

這一批沒有改動資料庫、權限規則或通知流程，也沒有對正式資料執行寫入。效能調整的預期效果只適用於上述頁面，不能代表所有網路條件下的實測速度。

## 實機與待驗項目

2026-10-22，使用者回報 iPhone 從主畫面開啟教會 OS，LINE 登入後回到原教會 OS 畫面；切換到其他 App 再返回也正常。這是使用者提供的實機操作結果，未記錄裝置版本、畫面錄影或登出重新登入條件。

關閉再開 App、未送出的長表單草稿、離線返回及 Mac Safari 的完整操作仍待實機驗收。本批程式碼若尚未合併發布，使用者回報驗證的是當時正式版，不能視為本批新變更的發布後驗收。全站 99% 目標仍待固定清單與完整實機證據。
