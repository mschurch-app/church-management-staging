# 新朋友表單送出回饋修復

會友回報按下原「很高興認識你・留下今日印記」沒有反應。程式可重現兩個回饋缺口：缺必填欄位只更新頂端formStatus，按鈕附近沒有提示；姓名核對等待時只disabled按鈕而不更換文字。無法據截圖推定個別會友已送到伺服器或單一根因。

按鈕改為「確認並送出資料」、明確button type；下方回饋與浮動提示同步，缺稱呼/性別會指出選擇項目並帶到欄位；核對/照片處理/送出有真實忙碌狀態和轉圈，成功捲至結果。預備送出中的未預期錯誤有捕捉，資料保留；沿用request_id與照片，不重複建檔。表單自行管理回饋，不由共用監看推測結果。

Chrome/WebKit各393/1440px四組實際頁面合成驗證：缺性別時不送出且可見提示、姓名核對進度、真實合成PNG處理為JPEG並隨payload送出、503後保留輸入、同一UUID與照片重試、明確成功結果。後端完整送出/照片/通知8項既有隔離回歸與Worker27項通過。未以真人LINE身分送出，不宣稱個別會友已完成或實體Android驗收。

僅前端，無資料庫變更。回退還原本PR頁面、模組與Worker；不刪除任何登記資料。
