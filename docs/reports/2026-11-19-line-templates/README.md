# LINE 罐頭文案庫與共用挑選介面

原先六類各一則，直接選取就取代全文。改為九個主要分類、49 則文案（另有自行撰寫），先比較摘要、閱讀全文，再明確套用。已修改內容需確認取代；取消保留原文。手機單欄、桌面雙欄。既有預覽、權限、相同請求重試及傳送紀錄保留。
