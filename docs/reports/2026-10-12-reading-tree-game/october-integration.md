# 箴言讀經測試接入新版遊戲

## 需求與入口

使用者要求原「箴言讀經測試」入口直接進入新版遊戲，繼續依原箴言計畫，第一次進新版先挑角色。沿用原 LIFF `2011645391-9t2SxuSG` 與 `tree-reading-october-test.html`，不要求改群組連結。

入口模組在原頁掛載共用遊戲畫面，保持 LIFF 實際頁面網址。素材使用遊戲目錄作為 base；頁內錨點仍指向原頁，避免跳入獨立體驗版。載入失敗提供重新開啟與原版恢復連結。

## 計畫、資料與身分

- 十月一日至三十一日，每日日期對應箴言同章；完整章節、原加入起日、最近七天補讀保持一致。
- 使用原同工 LINE 驗證與邀請碼。尚未加入者輸入原邀請碼；已加入者直接取回本人紀錄。
- 原十月隔離專案 `svwgfgyxxgbqabosriom` 新增 `tree_reading_october_game_states`，只保存新增角色、裝備、經驗相關狀態。正式會員的綁定／花園資料未改動。
- 新版每次讀取合併本人原讀經、澆水、手札；經驗由服務端紀錄計算。新的讀經、澆水與手札，和遊戲狀態以同一交易保存回原紀錄表，原同工統計繼續可用。
- `october_garden_save` 使用版本比對與服務角色專用權限；新表 RLS 啟用，匿名／一般登入角色無表存取及函式執行權。新增功能沿用原後端 LINE token 驗證、本人 subject 查詢；客戶端不能提交自訂 state／XP。
- 使用 request receipt 避免重送再次獎勵；並行衝突回報重新整理。
- 測試寫入仍限制十月期間；原紀錄保留，不清除舊資料。
- 初始角色為空。第一次開啟選擇男生／女生各三種配色，保存成功後進花園；之後可以更換。首次不可略過角色選擇，失敗在選角浮窗內提供訊息並保留選擇。

## 節慶與小組範圍

節慶測試日期沿用 `life-tree-festival-test-schedule.mjs`，與箴言閱讀日期分開。受難週每天的場景及配樂隨原表切換；節慶小物依當天讀經取得。

十月測試名單沒有正式小組欄位，不能推定同工都是同一小組。小組區清楚提供正式會友花園入口；實際組隊／關懷使用正式花園的既有綁定與組別。十月角色／遊戲進度與正式花園分開。

保留「原版讀經與紀錄」與原每日靈修試閱入口；`?legacy=1` 明確進原版。原靈修試閱的單一手札、LINE endpoint 與返回仍沿用既有流程。

## 每日恩典與主動攻擊

- 一般恩典小物改為完成「今日」讀經後，每天隨機一件花／燈／鳥／噴泉／果實。補讀與重送不額外發放；已有數量與花園紀念保留，放置只扣一份。這項規則同步到正式花園，取代原累積天數重複收集規則。
- 領取浮窗顯示圖像、用途、目前數量，提供回花園澆水與查看背包。節慶紀念另外依既有節期發放。
- 新版十月版才啟用獨立主動攻擊：普通事件間隔 8 秒，HP −5／MP −3；Boss 階段間隔 5 秒，HP −10／MP −6。伺服端核對當天、事件階段、戰鬥 session、冷卻時間及版本；數值在 0–100 內。正式會友花園維持既有按回合反擊。
- 倒數、蓄力進度、最後兩秒提醒、黑影與攻擊光球、守護者受擊、實際傷害數字與音效共同呈現。尊重減少動效及聲音偏好，倒數不逐秒透過朗讀器播報。
- 攻擊只有戰鬥浮窗在前景時才會請求；離開、切背景或完成事件即停，不計算離線補扣，不扣累積 XP、等級或收藏。已發出的單次請求可能仍完成；不自動補送逾時的攻擊。
- 明確保留「先回花園讀經」動線。HP 或 MP 不足會停止戰鬥並說明恢復方式；戰鬥從不阻擋讀經。
- 認真讀經首次完成該日補 HP +40／MP +20；澆水與首次手札各補 MP +10。重讀與反覆修改不重複補充。數值以 100 為上限。
- 十月隔離版無正式小組，噴泉改為下次首次澆水時額外補 HP／MP 各 10、消耗一次祝福；正式花園仍以小組關懷觸發，兩種模式清楚標示。五種一般小物都能在測試環境使用。
- 事件完成後有結果與生活提醒；戰鬥可選擇參與，頁面也可直接開始當日箴言。

## 共用資源與發布

延伸既有遊戲樣式、圖像、配樂及讀經載入器。攻擊樣式限 `data-october-test`；每日領取浮窗延伸既有會員花園樣式。HTML、入口及會員模組資源版本同步為 `20261012-october-game1`；共用會員版本也取得首次選角的清楚回饋與必要選擇行為。公開發佈授權沿用使用者本次「授權發佈」及接入指示。

隔離專案 schema 使用 `supabase/isolated/october-garden.sql`，不放進正式會員專案 migration 路徑。原十月函式新增 `garden_game` 分派，原 action 的行為保留。
