# 讀經小樹：花園與全副軍裝互動示範

日期：2026-10-12。版本：20261012-game2。用途：先審閱美術、裝備操作與成長回饋。

## 開啟

- 在 Mac Safari 開啟同目錄 `preview.html`，保留旁邊的 `assets/` 資料夾。此檔已內嵌樣式及程式，無需安裝套件。
- `index.html` 為模組版入口，供網站伺服器提供此整個目錄時使用。
- 初始提供 7 天示範紀錄與 220 XP，可以體驗一次小樹升級。示範紀錄存在目前瀏覽器，正式系統紀錄不變。

## 已實作

1. 手繪花園、小樹、守護者、六件軍裝、開合裝備包與三種小黑影素材。
2. XP、等級、本級進度與下一階段門檻；達標立即顯示升級。
3. 打開裝備包、選取、取出、穿戴展示、使用、收回；所有軍裝可借用體驗。
4. 寶劍攻擊與黑影消散、盾牌抵擋火箭、護心鏡擦拭、祝福小徑、頭盔拼圖與真理行動選擇；提供點按替代手勢。
5. 每日遭遇：普通 1–3 隻小黑影，或約 10% 機率遇到 Boss；Boss 三次攻擊，生命條與受擊回饋。
6. 每日首次守護普通 +10 XP、Boss +30 XP；Boss 與普通獎勵互斥。重新進入保留當日抽選與攻擊進度；完成後可以練習，不再加分。
7. 讀經 +20 XP、澆水 +5 XP、選填手札 +5 XP；同日期只獎勵一次。每個從起始日計算的同行週，至少 5 個讀經日期 +30 XP。
8. 預覽 Boss 造型入口，不改每日遭遇、不發 XP；方便審閱稀有畫面。
9. 台北日期切換、鍵盤焦點、原生浮窗、音效開關、減少動態效果、素材失敗重試與儲存不可用提示。
