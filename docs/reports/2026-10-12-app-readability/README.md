# 教會 OS 全頁可讀性修正

日期：2026-10-12。比較基準：`72f3f10f02a0f8959aec780a1c849194caf1e2cd`。

## 原因與修正

物品卡片的問題也出現在其他特殊控制：共用主要按鈕使用高優先權紅底及白字，覆蓋清單、設定分頁、場景控制的原有樣式；部分子文字仍保留深色或半透明顏色。公開頁的深色標題區則被全域標題色覆蓋。

- 共用主要按鈕新增明確的控制用途排除。清單與分頁採 `data-app-control="surface"`；特殊場景採 `custom`，保留各自完整的視覺設定。主要儲存動作維持既有配色。
- 教材清單與設定分頁同步選取狀態，包含懸停、已選取與子文字；拖曳、移除等次要操作使用次要按鈕。
- 修正登入說明、首頁通知及摘要小字、同工協作側欄、新朋友已選選項、主日週報步驟列，以及 LINE 預覽各功能的文字與背景。
- 深色公開標題區明確標記用途，標題與說明採成對設定。生命樹、節慶、每日靈修、代禱牆及今日經文的過淡文字或過亮按鈕個別修正。
- 共用元件規範加入控制用途與實際有資料狀態的驗收要求。資源版本統一為 `20261012-readable2`，同步直接、間接引用與 App Worker 快取。

沒有變更正式資料、Auth、RLS、權限識別、API 契約或資料庫結構。測試攔截所有業務請求，使用合成身分與合成資料；沒有送出正式通知或寫入正式業務資料。

### 對照與證據組成

`before-full.json` 保存固定舊版本的巡查；其中 28 個入口抵達的畫面檢出對比問題，同一問題會在不同狀態重複出現。`before-populated.json` 補入完整的功能設定與表單選項，不以空資料取代有內容的畫面。

`after-full.json` 保留原始整輪結果，包括登入修復頁自動轉址造成的一次檢查執行環境消失；這不是被隱藏的通過項。`after-rechecks.json` 補驗該入口，並使用完整合成資料重驗設定、新朋友及物品頁。`after-validated.json` 依入口與視窗尺寸合併，保留每項來源；`summary.json` 是合併後數量。登入返回頁僅驗畫面／既有轉址，不代表本次完成真實 LINE OAuth。

對比檢查合成實際祖先底色、半透明色及漸層色；不能精確涵蓋圖片、影片、陰影、所有祖先透明度與真實螢幕。停用狀態及純裝飾 SVG 不計入文字對比。畫面檢查不代表所有按鈕的業務流程通過。
