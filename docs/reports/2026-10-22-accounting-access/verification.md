# 財務會計分工繼承奉獻登錄權限

使用者確認將教會事工「財務會計」接上權限。M+ 主責或共同參與 accounting 的啟用帳號，透過既有 finance_user_can 動態取得 entry；移除分工即撤除這份繼承權限。現金核對與牧師複審不繼承。既有個別授權維持，權限頁標示繼承來源及並存舊授權，避免人員交接誤判。

權限仍限定 M+ 啟用帳號與已核對 canonical 身分；公開及 authenticated 角色不能直接列出財務權限清單。財務 API 每次請求重新檢查，不信任前端分工或職稱。點收同工清單改採有效授權，繼承成員可以被指定為點收人。未改動任何人的分工或個別角色，正式查詢時 accounting 分工人數為0。

隔離 Postgres 測試：主責與共同參與取得 entry、實際奉獻編號操作、移除分工後拒絕、未自動授予 cash_verify／approve、非本堂會、inactive及舊別名驗證、個別授權相容、函式權限隔離。帳號工具測試確認來源標示、canonical 合併與點收去重。

後端 migration 已套用、finance-cash v5 部署，verify_jwt 保留且已回讀比對來源。瀏覽器回歸使用模擬資料；iPhone實機及Safari未測試。沒有新增正式奉獻或發送通知。
