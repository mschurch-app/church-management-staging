# 逐筆奉獻自動加總與單人確認

每筆總額由該筆各奉獻分類自動加總，改為唯讀；整批仍由各筆加總。資料庫獨立計算分類金額，忽略前端傳入的 declaredTotal。每筆只需一位有登錄權限的同工勾選，儲存時由驗證過的 JWT 帳號記錄 canonical 確認人、時間及內容快照，不採信前端提供的確認人／時間。

畫面分為「本筆確認（1 位同工即可）」與「整批點收確認（兩位同工各自勾選）」，各自有說明。整批區列出明確步驟：第一位核對各筆、勾選自己的整批確認後存檔；第二位用自己的帳號開啟、核對、勾選後送師母複審。不能代勾另一人的整批確認。未儲存的本人勾選標明待儲存；儲存成功才呈現確認時間。

分類、金額、用途、奉獻者資料或日期變更時，畫面取消該筆確認及整批確認。相同內容重存時保留原逐筆確認人；來源 ID 必須屬於同批且不可重複，內容以伺服器快照比對，變更後的新確認只能記為目前登入同工。整批保存仍重置兩人確認，只有本次親自勾選者可隨存檔記錄自己的新確認。未逐筆確認的草稿可暫存，但不能進入整批確認或送審。師母、牧師後續審核順序不變。
