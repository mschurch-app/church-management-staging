# 十月同工小樹：遊戲內組隊與陪伴

邀請者在遊戲內選取已加入同工測試的人；受邀者在小樹旁看見邀請者頭像，點選「接受邀請」或「暫不加入」。不需貼碼、分享網址或離開遊戲。接受或換隊僅更動隊伍關係，讀經、手札、裝備與成長紀錄保留。

隊友頭像可開啟祝福（MP +10）、代禱（HP +10／MP +5）、活水支援（HP +20／MP +20）及支援請求。今日讀經完成可送一份活水支援；伺服器確認每日額度、HP／MP 100 上限與每日接受各 40 上限，包含舊關懷紀錄。LINE 頭像只取已驗證登入身分的圖片，分享可取消；未分享或載入失敗顯示花園角色。取消也隱藏待接受邀請的頭像。手札不公開。

資料為新增私有資料表及 service_role 專用 invoker RPC，保留現有自訂 LINE 驗證。前端功能僅在 October coworker mode 啟用，正式會員版不啟用新社交功能。舊邀請連結仍相容。
