# 同工箴言測試版組隊

## 目的與範圍

讓同工在原十月箴言測試入口邀請組隊、接受邀請、離隊與互送關懷，方便驗收多人互動。沿用遊戲既有浮窗、系統字體、自製 people 圖示、按鈕及狀態回饋；沒有新增管理頁入口。

## 權限與資料

- 使用原 October LINE 驗證與已登記的測試參與者名冊，不以管理員身分作為組隊門檻。
- 隊伍、成員、邀請及關懷只存於隔離專案 `svwgfgyxxgbqabosriom`。不讀寫正式會友或正式小組。
- 組隊連結不能登記新的測試參與者或授予管理權限；原本的同工測試邀請碼仍獨立驗證。
- 連結保存摘要，有效七天、最晚十月底到期。產生新的邀請會撤銷該同工先前的連結。
- 成員必須自行確認加入。隊友僅看見姓名及鼓勵留言，不分享 LINE 識別或讀經手札。
- 每日最多送三位、收到三份；同一對象每日一次。關懷補 HP 10、MP 15，最高 100。重送不重複發放，遊戲版本更新保護關懷結果。

## 操作與恢復

- 邀請經過 LINE 轉址、登入及原測試登記後仍保留；初次選角完成後才開啟組隊接受畫面。
- 載入與送出時停用重複操作；失敗保留鼓勵輸入，顯示重試提示。
- 過期或撤銷的邀請從網址及暫存清除，恢復自行邀請入口。
- 有另一支隊伍時不自動切換，須先離開原隊伍。
- 共享前端同步更新 `member.html`、核心及橋接模組版本；October 入口也更新版本。正式花園保留既有後端及小組權限。
