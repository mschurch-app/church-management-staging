# 教會 OS 第十二批：信息預備的未儲存保護與欄位定位

基準：正式 `10e9fe929ece6ca34829c75cbe89de699688015c`（#244）。接續既定的長表單錯誤定位、未儲存保護、失敗恢復及其他工作區推廣；本批範圍為信息預備工作室前端。

## 修正內容

1. **接入 App 保護。** 編輯信息與建立信息輸入時設定 `data-unsaved-changes`；操作期間以穩定的 `#content` 容器呈現 `aria-busy`，讓共用更新／重新整理流程辨識未存檔或進行中的操作。共用流程明確確認放棄後同步清除標記，避免接著又出現第二次離頁提示。草稿仍只在目前頁面記憶體。
2. **讀取失敗保留原工作。** 重新載入不再預先清除 dirty。清單失敗、內容失敗、歷史版本失敗或無效 payload 都保留原輸入與標記；驗證讀取回條的內容與項目識別後，才替換編輯資料。重新載入只詢問一次放棄確認。儲存回條先驗證 payload、項目 ID 與較新的版本，再清除標記。
3. **已建立但讀回失敗。** 收到有效建立回條後，清單或內容若讀不回，在目前頁面保留新項目 ID、停用再次建立，提示以「重新載入」讀回該項目；舊工作區輸入仍保留。讀回成功才切換至新項目，不再發一次 create。建立浮窗的關閉／Escape 也會確認未送出的輸入，取消建立不清除舊講章草稿。
4. **忽略過期背景回應。** 輪詢記錄目前項目、開啟序號與版本；若回應期間切換項目或完成儲存，忽略舊結果，避免將另一篇的工作紀錄或 NAS 回條放到目前信息。
5. **跨步驟修正欄位。** 沿用既有 `form-guidance`，針對信息必填、長度、大綱段數／確認、素材文字、投影片標題等列出可點選提示。按錯誤會切到對應步驟並在解鎖後聚焦。生成先核對自有素材、已確認大綱與正文長度，再保存／排隊，避免條件不足仍多存一版。明確儲存草稿仍可保存尚未確認的素材；沒有放寬原有生成門檻。
6. **修正儲存後的編輯資料來源。** 素材與投影片事件原本閉包參照舊物件；`saveDraft` 或採用 AI 草稿替換 draft 後，畫面可改但部分變更沒有進入新 payload。現在素材依 ID、投影片依目前索引更新當下 draft，測試直接核對送出的內容、筆記、核對狀態、投影片標題與畫面文字。
7. **區分操作用途。** 信息清單與五個步驟改用共用 surface 控制及 `aria-pressed`，讓選取項目／步驟有可見區別，避免全部呈現主要儲存按鈕樣式。保留 `aria-current`。工作室沿用系統字體，輸入至少 16 px 並依根字級放大。

本批只改工作室 JS、CSS、HTML 與 Worker 四個執行檔。工作室模組／樣式與 shell cache 統一為 `20261022-experience12`；保留前批資源及既有登入、堂會、後端授權、版本檢查、API 與模型工作設定。沒有資料庫遷移、模型更換或通知規則修改。

## 限制與待驗收

- 本批沒有新增信息裝置草稿；關閉／系統終止頁面後，未儲存輸入仍不能保證續填。第十批的持久草稿只適用排班。
- 新建成功後的待讀項目識別只保留於目前頁面。原有 request ID 與後端版本檢查仍負責原有重試規則；不宣稱所有網路故障都已解決，也沒有新增背景重送。
- 正式帳號的 AI 執行、NAS 備份、實際網路與多同工工作時間未在本輪寫入驗收。畫面中的 NAS／模型進度測試回條為合成資料。
- iPhone 主畫面 App、Safari／LINE 入口、實體鍵盤、讀屏、弱網、更新返回等仍待實機驗收。Mac Safari 本輪為本機合成流程，不宣稱全站實機 99%。
