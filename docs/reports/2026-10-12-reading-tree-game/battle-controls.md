# 戰鬥操作位置與完成後返回花園

## 使用者要求

手機戰鬥畫面下方的使用道具按鈕太低，需要滑動才看到，滑動後又看不完整戰鬥。戰鬥完成的慶賀畫面停留兩秒，直接返回花園。

## 修改

- 會員花園、原箴言同工入口與獨立體驗版共用新的戰鬥布局。`tree-game-battle.css` 限於遊戲戰鬥浮窗，沿用既有品牌、系統字體、圓角、圖示與按鈕樣式。
- 戰鬥浮窗依可用動態 viewport 與安全區域安排高度。標題、戰鬥畫面、精簡 HP／MP 與攻擊倒數、裝備選項和操作按鈕保持在同一畫面。長說明於獨立區域捲動；情境與經文可展開查看。
- 使用軍裝主按鈕放在戰鬥下方操作區，與返回花園並列；主要觸控範圍至少 44 CSS px。軍裝、黑影與反擊角色依戰鬥容器尺寸調整。較矮的橫向視窗使用左右布局。
- 事件操作完成並收到原後端成功回應後，才顯示「守護成功」慶賀畫面。保留原勝利光效、音效及回饋，兩秒後關閉戰鬥與相關浮窗，焦點與捲動回到花園。
- 不再自動開啟下一事件；每日已保存的下一事件繼續從花園進入。體驗版的 Boss 三階段保留明確的「繼續 Boss 體驗」按鈕。
- 可按「立即回到花園」提前返回。手動離開、開啟另一場戰鬥及離開頁面會清除舊倒數；回到快取的已完成戰鬥時重新提供兩秒慶賀。倒數核對事件 epoch，避免舊回呼關閉新戰鬥。
- 未完成、操作失敗、保存逾時或補充力量階段不啟動勝利返回倒數；原錯誤／重試回饋與事件保存契約保留。
- 入口、HTML 及異動的遊戲程式版本統一為 `20261012-battle1`。節慶圖像、音樂、閱讀計畫、後端及資料庫沒有異動。
