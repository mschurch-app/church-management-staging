# 會友、小組與出席：三階段工作區優化

2026-10-23。本機完成，尚未發布。基準為已發布 PR #252：`f2e7ebb83cbbc74591e3fcf76e6c1259e01874b8`。本批延續共用介面框架，依序改善會友名冊、小組／小家管理與出席登記。

## 三個階段

### 1. 會友名冊

- 整理姓名／電話／備註查詢與新增、匯出、選取等操作；小組、排序及身分條件收在原生展開區。
- 桌面編輯時讓表單與名冊並排，手機維持單欄；精簡檢視也能適應並排後的寬度。
- 會友選取使用完整 checkbox 標籤，擴大可點擊範圍。沿用既有查詢、分頁、選取、匯出、登入與背景返回邏輯。

### 2. 小組／小家管理

- 新增名稱、負責同工與地點搜尋，提供結果數與空結果提示；桌面編輯表單與名單並排。
- 必填／選填欄位清楚標示，修正欄位對齊與手機導覽遮擋。
- 取消、換筆、新增、重新讀取與封存前，先確認未儲存內容。儲存期間鎖定控制，失敗保留內容，成功後清除已提交草稿。
- 已存成功但重讀清單失敗時，明確提示重新讀取；封存／恢復依實際操作回報，失敗的封存清單讀取不會誤切換目前狀態。

### 3. 出席登記

- 新增小組／小家與聚會類型篩選。出席率依目前顯示的紀錄計算，明示只篩選已載入的最近最多 100 筆。
- 點名區新增姓名搜尋與即時出席／未出席人數；搜尋只隱藏不符合姓名，儲存仍包含全部勾選及原紀錄中的歷史姓名。
- 切換小組前確認清除勾選。純姓名搜尋不觸發未儲存提醒，真正的資料修改仍保留保護。
- 新增紀錄採裝置本地日期，修正台北凌晨可能預設為前一天的情況。
- 儲存失敗保留勾選；已儲存但清單更新失敗時，提供讀取重試，避免重複新增。

## 版本與範圍

三頁 HTML、各自 UI 模組、新樣式及 Worker 同步為 `20261023-people1`。Worker 保留既有資源並增加四個本批資源，共 95 個唯一預快取項目。資料服務、後端權限、資料庫及通知規則未改動；沒有資料庫遷移或後端部署。

草稿保護限於目前頁面的未儲存確認，並非關閉 App 後的持久草稿恢復。小組搜尋與出席篩選都限於已載入資料；不是全資料庫歷史搜尋。
