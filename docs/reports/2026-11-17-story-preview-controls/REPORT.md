# 協會照片故事製圖入口修正

待審稿原先只顯示照片與貼文，教師因此看不到版面、色系和生圖入口。作者現在可用「取回修改並製作預覽圖」將自己的待審稿取回，完成製圖再送審；審核者可用「請老師選色系並製作預覽圖」退回原投稿者。取回使用原身分、版本及 pending_review 狀態條件，與已核准發布操作並行時只有一方可成功。

草稿的「版面風格」「色系」及「產生預覽圖」集中於故事主圖區，整合產文與製圖按鈕也移到選擇之後。8 種風格及 22 種色系沿用現有選項，Canva brief 現在使用可讀的完整中文風格及色系名稱，包含主題與重點。成圖沿用一張 1080×1350 圖片與原照完整入框的合成流程。

API 隔離測試 21 項，Canva 工作測試 10 項通過，包含取回身分/狀態/版本限制、實際 Canva 請求帶入選擇、工作防重與成圖復原。瀏覽器驗收結果存於 ../2026-11-16-association-canva/browser-results.json。使用合成稿與已保存的 Canva 背景，未代真實老師取回稿件、通知或發 FB。實機 LINE 操作待確認。

回退可還原本 PR 前端三檔及 association-stories v5 的部署來源。取回後稿件保留為 changes_requested，可沿原流程繼續製圖及送審。
