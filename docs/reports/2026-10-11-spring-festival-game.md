# 春節遊戲說明、福字紅包與喜氣配樂

日期：2026-10-11

## 修改原因與呈現

使用者回報春節畫面出現整份測試行程，說明不符合當下玩法，房屋意象不理想，配樂不夠喜氣。

- 個人生命樹的節慶說明改為目前場景的三步玩法，移除換場日期、完整試玩行程及測試技術敘述。春節只呈現春節玩法；其他場景仍保留當日經文與事件。
- 春節房屋改為原創 SVG 福字紅包，搭配「新春蒙恩」春聯及既有七盞燈籠；點擊有彈跳回饋，平時輕輕擺動，遵循減少動態效果與背景暫停設定。
- 既有圖外互動按鈕同步換成福字紅包。完成今日澆水且照顧完挑戰後可互動三次，點亮燈籠；狀態提示依實際可操作條件呈現。
- 春節音樂改為原創 8 小節、128 BPM、15 秒循環，使用明亮彈撥旋律、木敲、低鼓與沙鈴。沿用現有音量與播放偏好。

## 影響與版本

正式十月生命樹與獨立節慶預覽共用插畫、節慶資料、動畫及春節音樂；更新相關模組、HTML 和 App 快取版本至 `20261011-spring-joy1`。每日場景切換日期維持既有設定。

## 檢查紀錄與待驗收

- 修改的 JavaScript 模組通過 `node --check` 語法檢查，差異通過 `git diff --check`。
- 產生春節音樂資產，PCM 661,500 bytes，22,050 Hz、16 bit、單聲道；只有春節音樂重新產生。
- 本次未執行功能測試或瀏覽器操作測試。Mac Safari／Chrome、iPhone 17 LINE／Safari／主畫面實機版面、互動與聽感保持待驗收，未宣稱達成 99%。
