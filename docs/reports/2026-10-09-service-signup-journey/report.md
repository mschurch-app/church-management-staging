# 完成頁、返回入口與恩典腳蹤

日期：2026-10-09。範圍：公開的 M＋主日服事登記。

## 使用流程

1. 送出或修改完成後，回到姓名清單；底部有主要按鈕「完成」，新增服事為次要操作。
2. 按「完成」開啟感謝頁，說明班表待負責人協調、候補邀請需在期限內回覆。
3. 日後從 M＋大雅教會首頁點「2027 讓我們一起服事」，用同一 LINE 帳號進入自己的清單，再按「修改我的登記」或該筆紀錄的修改按鈕。
4. 完成頁提供「完成，返回首頁」與「查看／修改我的登記」。返回首頁的連結已核對實際首頁及其既有 LINE 登入入口。

## 恩典腳蹤

- 清單、引導式登記／修改、完成頁皆顯示個人的年度卡片與鼓勵文字，可選擇年度。
- 依使用者確認的規則：`confirmed` 且服事日期早於台北當日，計入「累計服事」。今日及未來的已確認安排不提前計入。
- 今日／未來的有效登記另列為「已預備」；候補另列，不計入累計或已預備。
- 每年度以不同主日日期計次，包含已關閉季度的歷史，排除取消、婉拒、未確認的過去登記。
- 已計入紀錄保留職務及原季度資訊，清單顯示「已記入恩典腳蹤」；季度停止開放後仍可查看自己的紀錄。
- 統計載入失敗時顯示暫時無法載入，不假設數字為零，既有登記仍可操作。

## 實作與資料隔離

新增唯讀 RPC `service_signup_member_journey`，依現有已核准 LINE 會友綁定限制本人與堂會，並沿用活動登記索引。不新增資料表，不改寫實際登記，也不增加完成確認或排程；每次載入依排班狀態及台北日期重新計算。

RPC 固定空 `search_path`，僅授予 `service_role` 執行；前端仍透過原有 LINE token 驗證後的 Edge Function。匿名及一般登入者不能直接提供他人身分讀取。參考 [Supabase 資料庫函式與權限](https://supabase.com/docs/guides/database/functions)。

正式 `line-member` 原版本 26 與修改前原始碼相同；只增加統計讀取與回傳，已更新為版本 27，保留既有 LINE 認證、CORS、其他功能與登入設定。安全檢查前後均為原有 3 項，新增函式無相關警示；未擴大本次修改範圍。
