# 服事登記名單入口與名單檢視

2026-11-19。基準 main 3e9394819366fa16f4e8525be0d98212ad01062c。

服事中心原本只有意願自排與換班協調，沒有明確的登記名單入口。管理畫面以職務名額設定為主，姓名埋在每個職務之下。

## 修改

- 服事中心維持三欄入口：服事登記名單（直接連到名單檢視）、安排與協調、服事表輸出。主日總排、自排、換班及列印／發送原路由保留。
- 同一管理頁新增登記名單檢視，顯示姓名、主日日期、類別／職務、待確認、已確認、候補、候補待回覆。顯示筆數與去重後人數，依日期排列。
- 可搜尋姓名、切換雙月期別，展開日期／類別／狀態篩選；重新載入固定放在檢視切換旁。名單模式收起名額設定及流程說明，讓名單優先呈現。原名額與安排檢視及快速適配保留。
- 沿用 get_service_signup_admin RPC 與既有 service_signups 權限；沒有新增後端查詢、資料表、寫入、通知或擴大權限。原 RPC 僅回傳有效登記，取消／婉拒不列為有效名單。
- 更新首頁、導覽、名單資源版本及 Worker 快取版本，沿用既有安全更新機制。

## 驗收

- Chromium 與 WebKit，393／1440 CSS px，共四組隔離瀏覽器操作通過：從服事中心直接進入、姓名與狀態、同人多次登記計數、姓名搜尋、無結果、日期／類別／狀態篩選、期別切換、原安排檢視、職務範圍限制、權限撤回清空名單、唯讀操作與無水平溢出。
- 既有導覽／首頁12項與功能定義20項通過；Worker27項通過。語法與 diff 檢查通過。
- 首輪瀏覽器測試因同一職務多名登記人造成嚴格定位失敗，改成定位第一個職務文字。第二輪發現重新載入放在收合篩選內，已移到頂部，最終四組操作通過。
- 2026-11-19正式資料唯讀核對：2個期別、289個職務名額；登記表目前共1筆且為cancelled，有效登記0筆。新版若顯示空名單，符合本次核對時的正式資料；沒有新增合成登記至正式環境。
- 瀏覽器測試使用合成姓名與隔離 RPC，未發出任何正式寫入。iPhone／LINE及原帳號登入後的實機畫面仍待驗，未宣稱99%或全面實機通過。

## 發布與回退

依現有授權合併後逐檔讀回正式七個前端資源，與本機內容精確比較。回退可還原這七檔至基準版本，並發布新的Worker版本；不需資料庫回復，所有服事資料保留。
