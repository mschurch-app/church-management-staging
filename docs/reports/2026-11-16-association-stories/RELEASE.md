# 協會照片說故事

網站功能中心分為教會內容、協會內容、共用素材，既有路由與權限保留。新增協會「照片說故事」入口，使用既有網站／小組教材內容權限；只有目前指定的師母帳號能核准與連結協會 FB，系統擁有者不能略過這項審核。身分採用既有 canonical account 對應。

同工上傳 1–5 張照片，輸入真實事件描述，使用既有 Gemini 3.1 Flash Lite 產生可編輯文案。模型只接收描述及版面需求，不接收照片。圖片在瀏覽器縮放、重新編碼成 JPEG（移除 EXIF）；明暗與色彩微調後，照片完整置於相框，標題獨立排版，產出一張 1080×1350 主圖。提供整齊相框、主圖與小照片、故事橫列三種版面及三種深色調；產生文案後同步預覽主圖，同工可要求改版、修改主題後重做。

草稿、原照片與主圖在審核前保持私人。使用者可勾選捐款連結、協會網址及網站同步。送審與師母站內通知同一交易完成；可退回補充並通知作者。審核時鎖定版本、照片雜湊與主圖對應主題，核准後保存不可被作者修改的圖文快照。FB 只使用一張合成主圖；固定目標為使用者指定的 tcsca 粉專（API ID 311251732221816，公開個人檔案 ID 100064745854212），與教會 IG 分離。發布紀錄保存各照片 ID、發文開始點與回傳貼文 ID；不明結果先核對訊息、時間及照片 ID，不直接重發。FB 成功後網站失敗可單獨重試。

網站對接沿用 www.tcsc.org.tw 的既有內嵌首頁（Wix site 98eb2ead-75c9-4769-a5c2-bae76c432ec3）。實際瀏覽與內嵌 HTML 程式確認，既有最新消息已從同一 Supabase association_news 表讀取 published 資料（最新三則），也接受教會 OS 公開媒體。沒有覆蓋原網站或發布全站。探查期間準備的外層接點 e46e49e3-b18e-4a85-ab99-9d75d9f94daf 已停用（revision 3）；舊 JS URL 只保留無害停用相容程式，避免快取中的接點另建重複區塊。news_widget_verified_at 記錄既有接點的正式確認時間。

## 已完成隔離驗證

- 9 組真實 Postgres（PGlite）檢查：匿名／同工資料拒絕、RLS、權限、既有 LINE 身分、送審通知交易、師母專屬核准、退回及快照。
- 14 組後端檢查：來源與登入、作者隔離、媒體範圍、文案、主圖過期、公開同意、指定 FB 粉專、防重發、不明結果核對、網站分別重試。
- Chromium／WebKit 各 393px、1440px 共 4 組同工與師母流程：五張上限、同時產生圖文、更換版面、修飾、預覽、送審、核准一次。
- 同樣四組瀏覽器入口驗證：三個功能分區、每列三顆、無橫向溢出。正式既有網站接點另以瀏覽器及公開來源唯讀核對。
- 共用功能目錄 21、導覽 4、Worker 27 項回歸通過；Deno 型別檢查通過。

這些為隔離合成資料，不代表真實 iPhone、登入中的 Mac Safari、真實 FB 送達或模型內容品質已完成驗收。沒有發布任何協會測試貼文。

另增加一次性連線設定入口：由伺服器產生 256 位隨機能力憑證，只保存雜湊、20 分鐘內有效、完成即消耗；核對唯一協會粉專後，AES-GCM 加密保存發布憑證。能力憑證不授予內容審核或發布權限。網址片段載入即移除，頁面不使用持久儲存，輸入傳送前清空。新增 Chromium／WebKit 393px、1440px 共 4 組連線表單、失敗重試、成功清空、片段移除驗證，另含資料庫原子消耗、拒絕重用及過期檢查。
