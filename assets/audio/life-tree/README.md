# 生命樹聲音

本目錄八個 WAV 均由本專案 `scripts/generate_life_tree_audio.py` 產生，採數學振盪器合成原創簡短旋律與音效，沒有使用第三方錄音、下載音樂或付費服務。可執行該腳本重建完全相同檔案。

- `reading.wav`：16秒輕柔循環背景旋律。
- `storm.wav`：16秒風雨／強風陪伴旋律。
- `care.wav`：16秒除蟲／整理的輕快照顧旋律。
- `open.wav`：啟用／經文開啟提示。
- `celebration.wav`：澆水成功慶祝。
- `water.wav`、`wind.wav`：照顧小樹與挑戰提示。
- `journal.wav`：拾光收藏成功提示。

格式：22,050Hz、單聲道、16-bit PCM；共約2.2MiB。背景峰值0.38、音效峰值0.55，留有混音餘裕。播放器只在聲音已啟用且頁面可見時播放；首次使用說明預設勾選音效，按開始才啟動，也可取消勾選，選擇保留於原有 `lifeTreeSound`，說明完成記錄為 `october-life-tree-guide-v1`，均限同瀏覽器。重開、背景返回與pageshow會依已保存的同意先嘗試恢復播放；若瀏覽器以NotAllowedError阻擋，顯示輕觸頁面提示，在首次可信任touchend／click／Enter／空白鍵事件內同步啟用兩個播放器，不必尋找小喇叭。尚在等待的自動播放可由可信任操作接手；手動靜音仍保持。首次同意不等於瀏覽器永久允許自動播放，無法保證新LINE視窗無任何操作即出聲；小喇叭保留開關與真正載入失敗的重試。背景旋律依個人樹目前挑戰切換，照顧全部完成回到讀經旋律；使用同一播放器按需載入，沒有外部音訊請求或追蹤。
