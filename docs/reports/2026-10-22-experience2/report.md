# App 操作體驗改善：第二批

基準版本：6f79519e20f90a37d15731d29a25fed1c5b198f3。範圍為會友編輯、主日服事排班及 M+／既有同工工具的出勤與請假。保留既有 API、堂會、後端權限、資料結構及通知規則；未新增排程、雲端模型或背景智慧體。

## 操作與恢復

- 會友草稿只暫存在目前頁面記憶體。切到背景先隱藏私人內容，回來後重新向既有身份／權限流程核對，再恢復同一帳號草稿。核對失敗保持隱藏並可重試；權限撤回、換帳號或登出會移除舊編輯內容。沒有將會友個資存到瀏覽器持久儲存。
- 會友、排班、呈現設定及請假送出時鎖定整張表單，避免送出期間變更欄位或重複點擊；失敗保留輸入，恢復原本的停用狀態。
- 寫入已獲伺服器確認後，後續讀取失敗會明確區分「已儲存」與「清單尚未更新」，提供重新讀取並避免再新增。同工 API 須同時符合 HTTP 成功與 ok:true 才視為業務完成。
- 排班新增、會友編輯及服事項目設定取消／切換前保護未儲存修改。共用 draftGuard 可在編輯器移除時解除監聽，避免累積舊表單提示。
- 打卡有等待文字、重複點擊防護與獨立重新讀取入口；讀取失敗時停用打卡按鈕。請假日期先檢查起訖順序。審核結果寫入後讀不回時，舊審核按鈕維持停用。
- 請假與出勤清單讀取失敗保留先前內容並標示狀態。既有多單位同工頁面切換單位前會檢查草稿及進行中的操作。

## 版面與共用資源

沿用現有品牌、語意色與字體，將第二批頁面納入 app-experience.css。表單操作區可保持可見，鍵盤開啟時回正常文件布局；錯誤、提醒、完成及等待採文字配合色彩，等待使用小型動態提示，尊重減少動效。輸入文字至少 16px，手機操作列可換行。成功重新讀取後清除前次錯誤／提醒色彩。

HTML、模組及 Worker 的第二批資源版號一致為 20261022-experience2；保留前一批引用相容性。Worker 不新增私人 HTML、Auth 或 API 快取。

## 驗證

使用本機 Chrome、390 與 1440 CSS px 視窗、實際 HTML／UI 模組及隔離合成 API。48 項檢查全部通過，完整清單在 browser.json，測試入口 tests/experience2-browser.mjs。包括取消保留、背景草稿隱藏／恢復、撤權／換帳號／登出隔離、寫入失敗、已寫入但讀取失敗、重複送出、排班設定保護、打卡只讀恢復、請假日期及審核防重複；另驗證既有多單位頁面的單位切換與打卡。

共用 Worker 與 app-catalog 測試通過；變更 JavaScript 語法及 git diff --check 通過。已人工檢視手機會友、排班、同工頁面，以及桌面會友／排班的合成截圖。截圖由測試產生並保留於本機同目錄，不包含真實個資。

既有 phase3/browser.mjs 前 16 項通過，之後停在週報 #request-changes 按鈕遮擋檢查。以 git show HEAD 提供完全未修改的基準靜態資源重跑，同樣在相同位置失敗；本次沒有降低該檢查或宣稱完整回歸通過。此問題列入後續週報操作驗收。前批已記錄的 phase2/definitions 固定 44／目前 47 項及 metadata 缺值也仍待修。
