# 新希望專案報名

新希望基金會協辦標示及原始 Logo 加入報名網站。`?project=newhope#register` 預選專案。沿用完整學員、監護人、資格、保險與球衣表單，四步完成免繳費報名。

一人一組、限用一次。沿用既有營隊管理權限產生碼；資料庫只保存雜湊，明碼僅回傳一次，不進網址或稽核紀錄。核對環境、專案、效期與用量；資料列鎖及唯一索引防重用，同一 request 重試不重複核銷。

狀態 sponsored、應繳 0、付款時間空白；不產生付款訂單、繳費收據或思遠匯入。計入營隊名額、保留背號；後台分開篩選。以正式 Edge v43 為基礎保留 LINE Pay 已啟用狀態。

隔離交易測試全部回滾，涵蓋碼失效與跨環境/專案、重用、重送、背號、名額、加密、一般及現場方案、付款及收據拒絕、後台顯示與權限。Chrome/WebKit 手機與桌面四案例完成合成學員填表；後台兩案例驗證管理及查看角色。未作真人報名或實際扣款。

## 回退

如需暫停，停用 newhope 價格規則、隱藏前台專案及後台產碼入口。保留新增欄位、sponsored 狀態、名額計算與背號索引，保護已成立報名；不要刪除報名或碼，也不能退回忽略補助學員的舊背號查詢。一般付費流程保持運作。發布前函式與 Edge 副本保存在本機驗收目錄。

`tests/newhope/transaction.sql` 包含 BEGIN/ROLLBACK，勿移除回滾。`node tests/newhope/edge.mjs` 使用合成資料，禁止任何外部付款請求。實體 LINE/iPhone 真人送件仍待驗收。
