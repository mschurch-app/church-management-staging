# 請會友重新確認資料

會友名冊未封存的卡片提供「請會友重新確認資料」，顯示待本人確認；可取消。僅既有 members 權限可操作。同工按鈕只是標記，不發 LINE 訊息。

綁定會友下次進入既有 LINE 服務先開確認頁，核對電話、地區、生日、性別；姓名、小組及牧養資料仍由同工管理。送出更新原member，不建立新名冊，不改綁定與歷史。尚未綁定者仍須先完成本人核對與綁定。

確認要求用UUID識別；同筆標記/確認可重試，舊要求不能消除新要求，已撤銷綁定不能更新，失敗保留輸入。保留完成日期、提出日期及同工識別；取消也保留要求識別，不刪除資料。

驗證：隔離PGlite權限/堂會/本人/過期要求/重試/取消/撤銷/生日驗證通過；Chrome/WebKit手機393與桌面1440四組表單、送出失敗保留、重試、重新進入提示與解除通過；HTTP9、既有服務權限20、Worker27項通過。實體iPhone與真人標記未執行，不宣稱99%驗收。

發布順序：新增欄位/RPC、保留原部署依賴更新member-access兩個檔案、最後前端。回退前端及member-access原版本即可；保留新增欄位與確認紀錄，暫停新增標記；恢復時再接回待確認要求。無需刪除、封存名冊或更改登入。

順便修復既有update_verified_member生日正則的雙反斜線，改用數字字元類別；合法日期經測試可儲存，不合法日期仍拒絕。Supabase函式權限依官方文件核對：https://supabase.com/docs/guides/database/functions 。
