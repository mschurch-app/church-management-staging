# 教會 OS 第十三批：信息預備的裝置草稿續填

基準：正式 `d3ce80e0a8b9446a2b881bc38c3edc12ee45c0d9`（#245）。接續第十批的裝置草稿與第十二批信息工作區保護，處理「關閉後未儲存講章仍無法續填」的剩餘項目。

## 使用與保留範圍

- **自行開啟。** 預設不保留輸入；點「在這台裝置保留草稿」後，才在此瀏覽器／App 的 IndexedDB 保留目前這篇信息。每次成功更新可保留 24 小時，同一登入限一份裝置副本。成功提示以交易完成為準；等待中的最新輸入不以較舊交易的完成結果冒稱已保留。
- **重開後自行恢復。** 先顯示正式信息，另列裝置副本主題、基準版本與時間。點「繼續裝置草稿」才帶回；不自動寫入正式版本、生成 AI 或發送通知。讀取正式版本／切換信息不會自行刪除裝置副本；另一篇要保留時需先處理已有副本。
- **未填完可續填。** 保留信息欄位、筆記、素材內容及核對狀態、大綱、講章、投影片及目前步驟。必填欄位尚空白或投影片標題未填，也能保留。裝置驗證只容許這些編輯中的狀態；正式儲存仍走原契約與缺漏定位，沒有放寬送出門檻。素材搜尋、影片網址及建立信息浮窗不在保留範圍。
- **身分與版本核對。** 依伺服器確認的 Auth 使用者、同次登入 session ID 與 M+ 分區。JWT 識別僅供本機分區，不能授予權限。恢復前與恢復後送出前重新 `readAccess({fresh:true})`；恢復時另讀取正式信息，要求項目與基準版本一致。新版本、刪除、權限失效、到期或無效內容都拒絕套用，保留現有輸入及仍有效的副本；不自動合併。
- **保存與清除。** 儲存失敗／回條不完整保留副本與未儲存標記；收到有效新版本後清除這篇副本。裝置清除失敗另行提示「正式版本已儲存」，不把它報成正式儲存失敗。停止保留或刪除副本需確認，不清除頁面輸入。正式保存後需再自行開啟裝置保留，沿用排班草稿的操作方式。
- **多分頁與登出。** 沿用排班草稿同一交易內的 revision 比較方式，信息使用獨立資料庫；舊分頁不能覆寫／刪除較新副本。登出或身分改變立即隱藏私人信息、清空編輯欄位及清除舊登入副本；API 回應及恢復作業有世代檢查，較晚的讀取／儲存／身分回應不能重開舊內容。同次登入 token 更新可沿用。
- **失敗可繼續。** 空間不足、禁用裝置儲存或交易失敗會明示未保留；本頁原輸入與原有正式儲存仍可使用。沒有背景業務重送或離線 API 佇列。

新增兩個信息專用草稿模組；存放層沿用第十批已驗證的交易、revision、到期及清理方式，沒有修改排班模組。工作室 UI 沿用共用 surface、系統字體、語意色及 44 px 控制。HTML／工作室 JS、CSS、新模組與 Worker shell 同步 `20261022-experience13`，保留先前快取資源。沒有資料庫遷移、SDK／模型升級或通知規則調整。

## 限制與待驗收

1. IndexedDB 為同來源裝置資料，沒有新增加密。本機帳號／session 分區不是對抗同來源惡意程式、裝置管理者的安全邊界；共用裝置不宜開啟。若頁面關閉後才登出，無法接收清除事件，舊資料可能留至到期後再次存取／清理，但重新登入不能續填舊 session。
2. 保留限同一瀏覽器／App 與同一次登入；Safari、主畫面 App、LINE 入口不保證共用。瀏覽器清理、空間回收、私密模式或交易完成前被系統終止，仍可能失去最新輸入。輸入有 300 ms 合併等待，切到背景會嘗試立即處理，不能保證系統強制終止前一定完成。
3. 24 小時是每次成功更新後的期限，沒有背景定時刪除服務。恢復需能連線確認目前權限與正式版本；不保證完全離線續填。過長或格式不適用的編輯會明示未保留，不能把頁面仍可編輯解讀成裝置已保存。
4. 衝突不自動合併，也沒有新增衝突副本匯出；原有正式版本鎖與後端授權維持。正式多同工、AI／NAS 與實際弱網未在本輪寫入驗收。
5. iPhone 17 主畫面 App、Safari、LINE、系統終止／鍵盤／讀屏等仍待實機驗收。Mac Safari 此次為本機合成流程，不宣稱全站實機 99%。
