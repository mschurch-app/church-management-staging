# 新版遊戲節慶場景重設計

## 目的與範圍

依使用者要求，為新版讀經養成遊戲重新構圖，取代將舊版平面節慶 SVG 疊在新版樹木與角色後方的做法。接入正式共用會員花園、原十月箴言同工入口及獨立體驗頁。舊版讀經入口保持使用原來的節慶呈現。

## 圖像與構圖

18 張新繪環境底圖：跨年、春節、週年慶、聖靈降臨、端午、中秋、光明勇士、感恩節、聖誕節、生日，以及受難週八天。以既有 garden-dawn 與 garden-atlas 作畫風參考，統一細緻的手繪冒險遊戲材質、自然光與景深。場景為節期意象的遊戲花園，不作歷史遺址的考古重建。

| --- | --- |
| 跨年 | 靛藍湖畔、遠景煙火與暖燈 |
| 春節 | 紅燈籠、梅花、石庭院與遠景月門 |
| 週年慶 | 象牙白花園拱廊、白花與金色布幔 |

## 遊戲版面接入

- 新增共用 `tree-game-scenes.mjs` 與限遊戲頁作用的 `tree-game-scenes.css`，會員版與預覽版使用同一套映射。
- iPhone 直式與桌面分別調整樹、角色、事件與背包的比例、落地位置及留白；維持至少 44 CSS px 操作範圍、鍵盤焦點及減少動效支援。
- 事件從樹冠上方的大白卡移至左側地面，以小型光球與可讀標籤呈現；Boss 保留獨立形象與生命條。
- 夜景與安靜節期調整樹、角色及小物的光線；底部使用柔和暗色漸層承托按鈕，避免獨立灰綠色面板割裂畫面。
- 事件／戰鬥小場景沿用當前環境背景。
- 當前場景才載入圖片，不預載整套 18 張；載入中保留原花園底圖，失敗提供重試背景按鈕，不阻擋其他操作。
- 預覽頁將節慶選擇放在花園前；支援 `?scene=anniversary`，受難週加 `&day=1` 至 `8`，只接受既有場景清單。
- HTML、入口與異動模組版本使用 `20261012-scenes1`。既有未異動的音樂、軍裝與共用樣式版本保留。

## 原有資料契約

讀經日期、箴言計畫、角色進度、XP／HP／MP、軍裝功能、恩典小物、小組及 LINE 登入均沿用既有契約；本次沒有後端、資料庫或獎勵規則異動。節慶配樂與生日快樂歌繼續沿用。個人／小組任務仍屬先前企劃，未在這次視覺更新中實作。
