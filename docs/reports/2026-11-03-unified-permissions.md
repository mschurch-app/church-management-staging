# 同工權限勾選與選單一致化（2026-11-03）

入口：教會設定 → 同工帳號與權限；行政 → 奉獻與財務 → 同工權限設定亦導向同頁。

## 使用方式

選同工 → 勾選查看及所需操作 → 儲存權限。可搜尋功能；未開放功能只顯示查看開關。財務與支出權限整合在同一份表單，整份成功或整份回復。取消查看會取消相關操作；必要的資料查看依賴會自動勾選。角色範本、管理者指定首頁圖示、全域「開放／首頁／功能列」開關已從設定介面移除。功能中心及搜尋依有效權限顯示；既有名稱、排序、表單及使用者自己的常用排列仍保留。

## 規則整理

| 類型 | 授權及呈現規則 |
| --- | --- |
| 教會資料 | 原15組資料權限，查看／新增／修改／刪除／匯出／審核／管理分開勾選。畫面列出共用資料權限所涵蓋的功能。 |
| 關聯查看 | 小組、新朋友、讀經、LINE身分、通知需要會友查看；週報及教材需要關懷訊息查看。前後端檢查一致。 |
| 工作系統 | 同工工作與相簿、課輔、籃球以系統群組開放。沿用既有模組授權儲存欄位作相容，不再提供額外的首頁顯示設定。課輔另核對已連結人員身分；工時報表只對管理同工呈現。球隊系統仍核對隊內帳號。 |
| 主日奉獻 | 查看、登錄、點收確認、現金核對、最終複審。 |
| 金錢／物品收據 | 各自查看、草稿、正式開立、重印、作廢。 |
| 會計報表 | 查看已核准資料、匯出；不因此取得修改或核准權。 |
| 支出 | 自己提報、會計核對、師母複審、牧師核准及作廢、付款登錄。 |
| 課輔固定流程 | 鈺庭／恩茹排班；牧師／師母設定時薪；薪資流程及照片閱覽規則保留，這些流程身分不因一般功能勾選改變。 |
| 管理 | 擁有者保有完整管理權，不能由此撤除。系統監控依既有owner/viewer授權。 |
| 單一專責同工 | 新增無資料讀取權的portal登入授權，讓僅負責財務或其他系統的同工不必連帶取得會友名冊查看權。 |

原有實際權限在使用者儲存前保持原樣。沒有替真實同工預先勾選授權。既有首頁旗標資料保留作相容，已不再作一般功能選單的獨立否決條件。多個工具仍共用既有資料權限，並非新增每一路由的細分ACL。

## 實作與安全

`list_admin_permission_accounts`、`save_admin_permission_bundle`、`get_my_permission_navigation` 為公開schema的SECURITY INVOKER轉接，實作位於非公開church_auth schema，限定目前真實JWT身份。列名單及儲存重用assert_account_owner與session檢查；導覽只回傳本人權限。匿名不可執行。沒有新增對私人表的用戶直接讀寫權。

儲存重用原有身分別名合併、資料版本、交易、操作收據及稽核。財務版本與支出角色快照均核對；支出舊端點與新整合端點使用同一把交易鎖。重試沿用同一request ID，不會重複修改。權限儲存、財務與支出操作都留既有稽核。

主頁以一次權限profile RPC取代多個財務／課輔profile round trips；沒有以合成測試宣稱正式速度提升幅度。一般資料API仍保有原授權檢查。新資源與Worker版本為20261103-unifiedpermissions1。
