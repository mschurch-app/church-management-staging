# M＋教會 OS 課輔功能頁重製

僅修改教會 OS `/school/index.html`；獨立課輔網站、資料庫、登入與操作權限不變。

## 版面

- 六功能使用穩定表頭、六格功能切換與五大入口；留言、同工名冊及匯入保留於「全部課輔功能」。
- 到班打卡分成摘要、相機／條碼簽到、即時動態，桌面並排、手機依序。
- 排班、點名、學生與輔導將說明、篩選、操作、摘要及結果分區，避免整頁重複包一個大卡片。
- 報表採有標籤的種類／班級／月份選擇與獨立預覽區；保留既有列印規則。
- 來源控制元件以原始 HTML 切片移入新版面；所有原 main 的 ID、inline handlers 集合完全一致。inline 業務腳本與上一版相同，僅沿用既有 data-only auth 隔離。

## 驗證

- 120 項 Node 測試、18 項功能目錄、22 項 Worker 回歸通過。
- 393 × 852 與 1280 × 900 瀏覽器合成資料：六頁逐頁切換、單一可見面板、整頁無橫向溢出；已保存畫面。
- 既有角色、寫入失敗、點名去重、未儲存表單及相機卡住安全重讀測試保留。
- 未使用真實學生資料／相機打卡，未執行真實資料寫入；iPhone LINE／主畫面 App 與 Mac Safari 實機驗收待使用者實際操作。合成資料畫面不代表正式資料或 99% 實機驗收。

可重建：`python3 scripts/school/build-isolated-view.py --source <school-checkout> --source-ref 9fabf88a0c659d6dc02f86074f87b5257cf84694`；預覽：`python3 scripts/school/build-preview.py`。
